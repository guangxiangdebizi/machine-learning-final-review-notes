## 1. 必背定义

- 监督学习：有标签 `(x,y)`，学 `f(x)->y`
- 半监督学习：少量标签 + 大量无标签
- 无监督学习：无标签，学结构 / 表示
- 回归：连续值输出
- 分类：类别 / 类别概率输出
- 机器学习三步骤：**模型 -> loss -> 梯度下降**
- regularization：防过拟合
- bias 大：欠拟合
- variance 大：过拟合
- maximum likelihood：选最能解释已观测数据的参数

## 2. 必背公式

### 2.1 Regression

- `y_hat = w^T x + b`
- `MSE = (1/n) * sum_i (y_hat_i - y_i)^2`
- `Loss = MSE + lambda * ||w||^2`

### 2.2 Gradient Descent

- 梯度：loss 增大最快方向
- 更新：`w_(t+1) = w_t - eta * (dL/dw_t)`

### 2.3 Logistic Regression

- `z = w^T x + b`
- `sigmoid(z) = 1 / (1 + e^(-z))`
- `p(y=1|x) = sigmoid(z)`
- `L = -[y log p + (1-y) log(1-p)]`
- `softmax(z_i) = e^(z_i) / sum_j e^(z_j)`

### 2.4 Deep Learning / Forward

- `z^(l) = W^(l) a^(l-1) + b^(l)`
- `a^(l) = f(z^(l))`
- `ReLU(z) = max(0,z)`

### 2.5 Backpropagation

- `delta_out = y_hat - y`
- `dL/dw2 = delta_out * h`
- `dL/db2 = delta_out`
- `delta_hidden = delta_out * w2 * h * (1-h)`
- `dL/dw1 = delta_hidden * x`
- `dL/db1 = delta_hidden`
- `w <- w - eta * grad`

### 2.6 Attack / Defense

- `x_adv = x + epsilon * sign(grad_x L(theta, x, y))`

### 2.7 PCA

- `Sigma = (1/n) * sum_i (x_i - mu)(x_i - mu)^T`
- 第一主成分：`max_w w^T Sigma w, s.t. ||w|| = 1`
- 投影：`z = W_k^T (x - mu)`

### 2.8 GAN

- `min_G max_D V(D,G) = E_x[log D(x)] + E_z[log(1 - D(G(z)))]`

### 2.9 Lifelong Learning

- `L_total = L_new + lambda * sum_i b_i (theta_i - theta_i_old)^2`

### 09 Semi-supervised Learning

### 10 Unsupervised Learning

## 4. 必背流程模板

### 4.1 机器学习通用流程

1. 明确任务  
2. 选模型  
3. 定义 loss  
4. 梯度下降优化  
5. 看训练 / 测试误差

### 4.2 梯度下降题

1. 求导  
2. 代更新式  
3. 逐轮迭代

### 4.3 前向传播题

1. `z = Wx + b`  
2. 过激活  
3. 逐层往后算

### 4.4 反向传播题

1. 先算 `y_hat`  
2. 写输出层误差项  
3. 链式法则往前传  
4. 写梯度  
5. 更新参数

### 4.5 PCA 题

1. 中心化  
2. 协方差矩阵  
3. 特征分解  
4. 取最大特征值对应方向

### 4.6 GAN 题

1. 说 G / D 角色  
2. 说交替训练  
3. 说难点：不稳定 / mode collapse

### 4.7 Stable Diffusion 题

1. 正向加噪  
2. 反向去噪  
3. latent diffusion  
4. U-Net 预测噪声

## 5. 必背易错点

- 监督学习 != 分类
- 半监督 != 无监督
- Logistic Regression 是**分类**
- 梯度是增大方向；更新走负梯度方向
- likelihood 大好；cross entropy 小好
- loss 不一定轮轮下降
- 前向传播顺序别写反
- 反向传播一定用链式法则
- ReLU 常用于隐藏层；sigmoid 常用于二分类输出
- PCA 去相关 / 正交，**不保证独立**
- PCA 不利用标签，可能不利于分类
- 异常 != 坏，只是偏离正常
- FGSM 改的是输入，不是参数
- GAN 是 G、D 交替训练
- Stable Diffusion 重点是 **latent diffusion**
