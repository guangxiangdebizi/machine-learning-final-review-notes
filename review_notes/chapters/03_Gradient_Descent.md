## 4. 高频知识点整理

### 4.1 梯度下降的基本思想

目标：最小化损失函数 `L(w)`。

更新公式：

`w_(t+1) = w_t - eta * dL/dw`

其中：

- `eta`：学习率
- `dL/dw`：当前点的梯度

为什么减号？

- 因为梯度指向 loss 增大的方向
- 我们要让 loss 变小，就要往反方向走

### 4.2 学习率的作用

#### 学习率太大

- 容易震荡
- 甚至越过最优点

#### 学习率太小

- 收敛很慢
- 训练效率低

PPT 的形象说法：

- 大步迈，先探索
- 小步踱，再细化

### 4.3 SGD

#### Batch Gradient Descent

- 每次用全部样本算梯度
- 稳定但慢

#### Stochastic Gradient Descent

- 每次只用一个样本更新
- 快，但噪声大

#### Mini-batch SGD

- 折中方案
- 实际最常用

### 4.4 Feature Scaling

PPT 强调了一个很实用的点：  
如果不同维度尺度差太大，梯度下降会走得很别扭。

原因：

- 某些维度变化很快
- 某些维度变化很慢
- 等高线会很狭长，更新路径来回震荡

常见处理：

- 标准化
- 归一化

### 4.5 常见优化器

#### SGDM（动量）

- 引入历史梯度信息
- 减少来回摆动
- 有助于冲出平缓区或局部困境

#### Adagrad

- 对不同参数自适应调整步长
- 历史梯度大的方向，后续步长会变小
- 缺点：后期步长可能衰减过快

#### RMSProp

- 改进 Adagrad
- 用指数加权方式估计梯度平方
- 缓解步长过快衰减

#### Adam

- 动量 + RMSProp 的结合
- 工程上常用
- 收敛快、较稳

## 5. 易混点 / 易错点

- 梯度是“增大最快方向”，**不是最小方向**。
- “梯度为 0”不一定是全局最优，也可能是鞍点或局部点。
- SGD 并不是一定比 Batch 更差；它虽然有噪声，但常常更快。
- Feature Scaling 不是改变任务本身，而是让优化更顺畅。
- Adam、RMSProp 是优化技巧，不是新的损失函数。

## 6. 关键例题

### 例题 1：普通梯度下降计算题

**题目：**  
已知损失函数

`L(w)=w^2+5w+6`

学习率 `eta=0.1`，初始值 `w0=2`。  
用普通梯度下降法计算 3 次迭代后的参数值。

**答案要点：**

1. 求导：`dL/dw = 2w + 5`
2. 更新公式：`w_new = w_old - 0.1*(2w_old+5)`
3. 计算：
   - `w1 = 2 - 0.1*(9) = 1.1`
   - `w2 = 1.1 - 0.1*(7.2) = 0.38`
   - `w3 = 0.38 - 0.1*(5.76) = -0.196`

**最终答案：** `w3 = -0.196`

### 例题 2：为什么要做 Feature Scaling？

**题目：**  
某模型两个特征分别是“年收入（万元）”和“年龄（岁）”，前者数值范围远大于后者。若直接做梯度下降，为什么可能训练很慢？如何改进？

**答案要点：**

- 不同特征尺度差异会让损失面的等高线很狭长。
- 梯度下降会在某一方向上大幅震荡，在另一方向上缓慢前进。
- 会导致收敛慢、学习率难调。
- 解决方法：标准化 / 归一化 / whitening 等尺度处理。

## 7. 本章速记

- 梯度：loss 增大最快方向
- 更新：负梯度方向
- 学习率太大：震荡
- 学习率太小：太慢
- SGD：快但有噪声
- Feature Scaling：让优化更好走
- Adam：动量 + 自适应学习率
