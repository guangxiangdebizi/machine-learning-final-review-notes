## 3. 结合 PPT 必须掌握的内容

PPT 这章给出的核心信息：

- 神经网络是一连串 **Matrix Operation**
- 输入可以是高维，比如 `Input 256 维`
- 输出可以是分类结果，比如 `Output 10 维`
- 需要自己设计：
  - 有多少层 layer
  - 每层多少个 neuron
- 新样本到来后，参数会在原有基础上继续更新

这说明深度学习就是：  
**用多层线性变换 + 非线性激活，逐层提取更复杂特征。**

## 4. 高频知识点整理

### 4.1 神经网络的基本结构

一个典型前馈神经网络包含：

- 输入层
- 若干隐藏层
- 输出层

每一层都做两件事：

1. 线性变换  
   `z^(l) = W^(l) a^(l-1) + b^(l)`
2. 非线性激活  
   `a^(l) = f(z^(l))`

### 4.2 为什么要“深”

如果只有线性层叠加而没有激活函数，那么多层线性变换仍然等价于一层线性变换。  
真正让模型表达能力变强的是：

- 多层结构
- 非线性激活函数

### 4.3 常见激活函数

#### Sigmoid

`sigmoid(z) = 1 / (1 + e^(-z))`

特点：

- 输出范围在 `(0,1)`
- 常用于概率解释
- 但深层网络里容易引起梯度变小

#### ReLU

`ReLU(z) = max(0, z)`

特点：

- 计算简单
- 梯度传播更稳定
- 负区间可能出现“死亡 ReLU”

### 4.4 前向传播的本质

从输入层开始，逐层做：

- 加权求和
- 加偏置
- 过激活函数

直到得到最终输出。

考试里常见要求：

- 给一张小网络图
- 让你从左往右算到输出

## 5. 易混点 / 易错点

- **先乘权重再加 bias，再过激活函数**，顺序不要写反。
- 多层网络不是“层数越多越好”，太深可能更难训练。
- 输出层激活函数要看任务：
  - 二分类常用 sigmoid
  - 多分类常用 softmax
  - 回归输出层有时直接线性输出
- 神经网络的“深”不是指数据维度大，而是层数多。

## 6. 关键例题

### 例题 1：前向传播手算

**题目：**  
设输入 `x=[1,2]^T`，隐藏层有 2 个神经元：

- `W1 = [[1,0],[-1,1]]`
- `b1 = [0,1]^T`
- 隐藏层激活函数为 ReLU

输出层：

- `W2 = [0.5,-1]`
- `b2 = 0`
- 输出层激活函数为 sigmoid

求网络最终输出。

**答案要点：**

1. 隐藏层线性输出：
   - 第 1 个神经元：`1*1 + 0*2 + 0 = 1`
   - 第 2 个神经元：`-1*1 + 1*2 + 1 = 2`
2. 过 ReLU：
   - `a1 = [1,2]^T`
3. 输出层线性输出：
   - `z2 = 0.5*1 + (-1)*2 = -1.5`
4. 最终输出：
   - `y_hat = sigmoid(-1.5) ≈ 0.1824`

### 例题 2：为什么激活函数不能省？

**题目：**  
为什么神经网络如果每层都不加激活函数，表达能力会大幅下降？

**答案要点：**

- 因为多层线性变换复合后仍然是线性变换。
- 没有非线性，网络就无法表达复杂非线性关系。
- 所以深度学习的关键不是只有“很多层”，而是“很多层 + 非线性”。

## 7. 本章速记

- 神经网络 = 多层线性变换 + 激活函数
- 前向传播：乘权重 -> 加偏置 -> 过激活
- `z = Wx + b`
- Sigmoid：压到 `(0,1)`
- ReLU：`max(0,z)`
- 考试高频：手算前向传播
