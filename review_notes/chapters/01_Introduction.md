# 01 Introduction：机器学习基础框架

## 1. 老师点名重点

- 监督学习、半监督学习、无监督学习的概念必须清楚。
- 回归、二分类、多分类要会区分。
- 机器学习三大步骤必须掌握：
  1. 建立模型 / 假设函数
  2. 定义 loss function
  3. 用梯度下降优化
- 要理解 loss function 的含义。
- 要知道 regularization 的作用。
- 要理解 bias 与 variance。

## 2. 本章不考 / 低优先级

- 本章以概念理解为主，**无复杂公式推导要求**。

## 3. 结合 PPT 必须掌握的内容

PPT 开头强调：**机器学习就是“自动找函数”**。  
也就是：给定输入和期望输出，让机器自己找到一个合适的映射函数。

PPT 中给出的任务视角：

- **回归**：输出连续值
- **分类**：输出类别
- **生成**：输出文本、图像等内容

PPT 还强调了两件事：

1. 你要先告诉机器“想找什么功能的函数”——这就是**建模**。
2. 你要告诉机器“什么样算好”——这就是**损失函数**。

## 4. 高频知识点整理

### 4.1 监督学习、半监督学习、无监督学习

#### 监督学习 Supervised Learning

- 训练数据有输入 `x` 和标签 `y`
- 目标：学到 `f(x) -> y`
- 常见任务：
  - 回归
  - 分类

**例子：**

- 用房屋面积预测房价
- 用图片预测猫狗类别

#### 半监督学习 Semi-supervised Learning

- 训练数据里**只有少量样本有标签**
- 大量样本无标签
- 目标：利用未标注数据帮助提升模型

**例子：**

- 100 张已标注病理图像 + 5000 张未标注图像做分类

#### 无监督学习 Unsupervised Learning

- 训练数据**没有标签**
- 目标：发现数据内部结构、分布或表示

**例子：**

- 聚类
- 降维
- 词向量学习

### 4.2 回归、二分类、多分类

- **回归**：输出连续数值  
  例如：股价、转向角度、温度、购买概率评分
- **二分类**：输出两个类别之一  
  例如：垃圾邮件 / 非垃圾邮件
- **多分类**：输出多个类别之一  
  例如：手写数字 0-9 分类

### 4.3 机器学习三大步骤

#### Step 1：建立模型

- 先确定函数形式
- 例如：
  - 线性模型
  - Logistic Regression
  - 神经网络

#### Step 2：定义损失函数

- 损失函数衡量“预测有多差”
- 常见：
  - 回归：MSE
  - 分类：Cross Entropy

#### Step 3：梯度下降优化

- 不断调整参数，让 loss 变小
- 本质：沿着**负梯度方向**更新参数

### 4.4 正则化、Bias、Variance

#### 正则化 Regularization

作用：

- 限制模型过于复杂
- 减少对噪声的过拟合
- 提升泛化能力

可以简单理解为：  
**不让模型为了拟合训练集而把曲线拧得太“奇怪”。**

#### Bias

- 模型太简单
- 连大致趋势都学不好
- 对应 **underfitting**

#### Variance

- 模型太敏感
- 训练集拟合很好，测试集表现差
- 对应 **overfitting**

## 5. 易混点 / 易错点

- **监督学习 ≠ 分类。** 回归也属于监督学习。
- **半监督学习 ≠ 无监督学习。** 半监督仍然有少量标签。
- **loss 小**表示模型当前更好，不代表一定已经泛化最好。
- **正则化**不是让 loss 一定更小，而是让模型更稳、更不容易过拟合。
- **bias 大**和**variance 大**不是同一件事：
  - bias 大：模型太弱
  - variance 大：模型太灵活

## 6. 关键例题

### 例题 1：判断任务类型

**题目：**  
判断下列任务分别属于监督学习、半监督学习还是无监督学习，并说明理由：

1. 用历史房价数据预测未来房价
2. 只有 100 条带标签评论和 1 万条无标签评论，做情感分类
3. 把用户按消费习惯自动分群

**答案要点：**

1. 监督学习：有输入和真实房价标签，属于回归。
2. 半监督学习：标签很少，但任务目标仍是分类。
3. 无监督学习：没有标签，目标是发现群体结构。

### 例题 2：Bias 与 Variance 分析

**题目：**  
某模型在训练集和测试集上都表现很差；另一模型训练集表现很好但测试集很差。分别说明它们更可能是哪类问题，并给出改进思路。

**答案要点：**

- 第一种：更像 **bias 大 / 欠拟合**
  - 改进：用更强模型、增加特征、训练更久
- 第二种：更像 **variance 大 / 过拟合**
  - 改进：正则化、dropout、数据增强、早停、简化模型

## 7. 本章速记

- 机器学习：自动找函数
- 监督：有标签
- 半监督：少量标签 + 大量无标签
- 无监督：没标签
- 回归：连续输出
- 分类：离散类别输出
- 三步骤：模型 -> loss -> 梯度下降
- 正则化：防过拟合
- bias 大：欠拟合
- variance 大：过拟合
