# 11 Explainable / Interpretable ML：可解释机器学习

- 概念理解即可。
- 重点是知道：**为什么需要可解释性**。

## 2. 本章不考 / 低优先级

- 老师明确说：**不作为重点章节**。
- 但可能以概念题、开放题出现。

## 3. 结合 PPT 必须掌握的内容

PPT 里给出的典型问题非常有代表性：

- 招聘筛选时，模型到底看的是能力还是性别？
- 犯罪评估时，模型到底看的是证据还是肤色？
- 金融拒贷为什么要给理由？
- 模型诊断为什么不能只看正确率？

所以这章最核心的问题是：

> 模型做出了一个决定，我们能不能说明“它为什么这么做”？

## 4. 高频知识点整理

### 4.1 什么是可解释 / 可理解

#### Interpretable

- 模型结构本身就比较容易理解
- 例如：浅层决策树、线性模型

#### Explainable

- 模型本身可能很复杂
- 但可以借助其他方法对它的行为做解释

### 4.2 为什么要解释模型

主要原因有三类：

1. **公平性 / 合规性**
   - 决策不能带来不合理歧视
2. **可追责**
   - 重要决策要能说明理由
3. **模型诊断**
   - 发现模型到底学到了什么、有没有学偏

### 4.3 常见解释视角

#### 全局解释 Global Explanation

- 解释整个模型总体在干什么

#### 局部解释 Local Explanation

- 解释某一个具体样本为什么被这样判断

### 4.4 常见方法（理解层面）

- 显著性图 / saliency
- 扰动法 / perturbation
- 用简单模型去模仿复杂模型（surrogate model）

## 5. 易混点 / 易错点

- “模型准确率高”不代表“模型可信”。
- 可解释性不是只给开发者看的，在金融、医疗、司法里尤其重要。
- 可解释不一定要求模型本身简单，也可以是“复杂模型 + 解释工具”。

## 6. 关键例题

### 例题：为什么不能只看准确率？

**题目：**  
一个模型在贷款审批任务上准确率很高，为什么还需要研究它的可解释性？

**答案要点：**

- 因为它可能学到了不应依赖的特征，例如性别、种族、无关背景。
- 金融决策往往需要给用户说明拒绝原因。
- 只有知道模型为什么这么判，才能发现偏见和错误规则。

## 7. 本章速记

- 可解释性：解释模型为什么这么判
- 原因：公平、合规、诊断
- 全局解释：解释整体
- 局部解释：解释单个样本
- 这章不是重点，但概念题容易出
