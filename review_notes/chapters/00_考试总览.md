### 第一步：先把“老师点名的词”背成一句话解释

- 什么是 supervised / semi-supervised / unsupervised

- 什么是 regularization
- 什么是 bias / variance
- 什么是 maximum likelihood
- 什么是 sigmoid / ReLU
- 什么是 backpropagation
- 什么是 PCA 主成分
- 什么是 anomaly
- 什么是 generator / discriminator
- 什么是 diffusion / denoising

### 第二步：把计算流程练熟

- 梯度下降：会写更新公式，会算 2-3 轮
- 前向传播：会算加权和、加 bias、过激活函数
- 反向传播：会按链式法则从输出层往前推
- FGSM：会写 `x_adv = x + epsilon * sign(grad_x L)`

## 6. 临考前一页速记

- 回归输出：**连续值**
- 分类输出：**离散类别 / 类别概率**
- 机器学习三步：**模型、损失、优化**
- 最大似然：**让已观测数据出现的概率最大**
- Logistic：`sigmoid(w^T x + b)`
- 交叉熵：预测越接近真实标签，损失越小
- 梯度下降：**沿负梯度方向更新**
- 前向传播：线性变换 + 激活
- 反向传播：链式法则求梯度
- PCA：**找方差最大的投影方向**
- 异常检测：**找“明显不像正常样本”的点**
- GAN：G 负责生成，D 负责判别，二者对抗训练
- Stable Diffusion：**加噪训练，去噪生成**

## 7. 综合例题

### 例题：老师如果出一道“开放综合题”，最可能怎么问？

**题目：**  
结合机器学习课程内容，说明一个完整机器学习系统从建模到训练再到应用的大致流程，并举例说明其中可能出现的过拟合、梯度优化困难和模型泛化问题。

**答案要点：**

1. 先确定任务类型：回归 / 分类 / 生成 / 检测。
2. 选模型：线性模型、Logistic、神经网络、GAN、扩散模型等。
3. 设计损失函数：MSE、Cross Entropy、对抗损失等。
4. 用梯度下降或其变种训练。
5. 训练中会遇到：
   - 过拟合 -> 正则化、dropout、数据增强
   - 梯度问题 -> 调学习率、ReLU、Adam、残差/规范化思想
   - 泛化问题 -> 验证集监控、早停、更多数据
6. 最终评价模型效果，并说明不同任务使用不同指标。
