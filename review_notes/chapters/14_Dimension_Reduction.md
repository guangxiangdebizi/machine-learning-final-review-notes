## 3. 结合 PPT 必须掌握的内容

PPT 这章反复强调：

- 投影后要尽量保留差异，**方差大更好**
- 主成分之间要**正交**
- 对角化可以让不同维度彼此独立
- 如果投影方向选错，会把原本可区分的类别压得分不开

这正是 PCA 的核心直觉。

## 4. 高频知识点整理

### 4.1 为什么要降维

目的：

- 压缩特征维度
- 去冗余
- 降噪
- 便于可视化
- 提高后续模型效率

### 4.2 PCA 的核心思想

PCA 要找一个新的坐标系，使得：

1. 第一主成分方向上数据方差最大
2. 第二主成分与第一主成分正交，且方差次大
3. 依次类推

也就是说：

> 选择最能保留数据差异的投影方向。

### 4.3 PCA 的标准步骤

1. 对数据做中心化  
   `x_i <- x_i - mean(x)`
2. 计算协方差矩阵  
   `Sigma = (1/n) * Σ (x_i - mu)(x_i - mu)^T`
3. 求协方差矩阵的特征值和特征向量
4. 按特征值从大到小排序
5. 取前 `k` 个特征向量组成投影矩阵 `W_k`
6. 做投影：
   `z = W_k^T (x - mu)`

### 4.4 为什么主成分要正交

PPT 里说得很直白：

- 如果方向彼此正交，就互不影响
- 内积为 0

这有助于：

- 避免重复表示同一类信息
- 让新的特征更独立

### 4.5 PCA 的局限

- PCA 是**无监督**方法
- 它只看方差，不看类别标签
- 所以“方差最大”不一定等于“分类最有利”

PPT 里“投影到红线导致类别分不开”的例子，就是在提醒这一点。

## 5. 易混点 / 易错点

- PCA 选的是**方差最大的方向**，不是“样本最多的方向”。
- PCA 是无监督降维，不利用标签。
- 特征值越大，对应方向保留的信息通常越多。
- 主成分是新的坐标方向，不是原来某一个单独特征。

## 6. 关键例题

### 例题 1：主成分判断题

**题目：**  
若二维数据中心化后的协方差矩阵为

`Sigma = [[9,0],[0,1]]`

问第一主成分方向是什么？为什么？

**答案要点：**

- 特征值分别为 9 和 1。
- 第一主成分对应最大特征值 9。
- 因此第一主成分方向就是 `x1` 轴方向。
- 原因：该方向方差最大，保留的信息最多。

### 例题 2：为什么 PCA 可能不利于分类？

**题目：**  
说明为什么 PCA 虽然保留了总体方差，却可能让两个类别更难区分。

**答案要点：**

- PCA 不利用标签。
- 它关心的是整体方差，不关心类别边界。
- 如果类间可分信息不在最大方差方向上，降维后可能把类别压得更近。

## 7. 本章速记

- PCA：最重要的降维方法
- 目标：保留最大方差
- 步骤：中心化 -> 协方差 -> 特征分解 -> 取前 k 个主成分
- 主成分要正交
- PCA 无监督，不一定最利于分类
