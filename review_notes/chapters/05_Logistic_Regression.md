# 05 Logistic Regression：逻辑回归

## 1. 老师点名重点

- Logistic Regression 原理必须理解。
- 激活函数的概念要懂。
- 机器学习三步骤在逻辑回归中的体现要会说。
- sigmoid 等函数的基本形式要理解。

## 2. 本章不考 / 低优先级

- **不考复杂数学推导。**
- 重点是：模型结构、概率解释、loss、线性可分限制。

## 3. 结合 PPT 必须掌握的内容

PPT 明确给出的关键信息：

- `L` 是 likelihood，**越大越好**
- 训练时会把它转成要最小化的量
- 各训练样本上的 **cross entropy 求和**
- Logistic Regression 只能做**线性分割**
- 若线性分不开，就要考虑特征变换或更复杂模型

## 4. 高频知识点整理

### 4.1 Logistic Regression 做什么

它本质上是一个**分类模型**，尤其适合二分类。

基本形式：

1. 先做线性变换  
   `z = w^T x + b`
2. 再过 sigmoid  
   `p = sigmoid(z) = 1 / (1 + e^(-z))`

其中：

- `p` 可以理解为样本属于正类的概率

### 4.2 为什么要用 sigmoid

线性输出 `z` 的取值范围是整个实数轴。  
sigmoid 可以把它压到 `(0,1)` 区间，便于解释成概率。

特点：

- `z` 越大，`p` 越接近 1
- `z` 越小，`p` 越接近 0

### 4.3 机器学习三步骤在逻辑回归中的体现

#### Step 1：模型

`p(y=1|x) = sigmoid(w^T x + b)`

#### Step 2：损失函数

通常使用交叉熵损失：

`Loss = -[ y log p + (1-y) log(1-p) ]`

多样本时，对所有样本求和或求平均。

#### Step 3：优化

- 对 loss 求梯度
- 用梯度下降或 Adam 等方法更新参数

### 4.4 likelihood 与 cross entropy 的关系

PPT 已经给出直观关系：

- likelihood 越大越好
- 但训练更常做的是最小化损失

所以通常把“最大化 likelihood”改写成：

- 最小化负对数似然
- 也就是常见的 cross entropy

### 4.5 逻辑回归的局限

PPT 明确指出：

- Logistic Regression 只能做**线性分割**

所以如果数据天然是非线性可分的：

- 可以做特征变换
- 或直接换成更强模型（如神经网络）

## 5. 易混点 / 易错点

- 逻辑回归虽然名字里有“回归”，但它主要用于**分类**。
- sigmoid 是激活函数，不是损失函数。
- likelihood 越大越好；cross entropy 越小越好。
- 逻辑回归输出的是概率，不是已经离散化后的类别编号。
- softmax 常用于多分类，sigmoid 更典型用于二分类。

## 6. 关键例题

### 例题 1：手算一次 Logistic 输出与损失

**题目：**  
设 `x=[1,2]`，`w=[0.5,-1]`，`b=0`，真实标签 `y=1`。  
求：

1. 线性输出 `z`
2. 概率 `p`
3. 单样本交叉熵损失

**答案要点：**

1. `z = 0.5*1 + (-1)*2 = -1.5`
2. `p = sigmoid(-1.5) ≈ 0.1824`
3. 因为 `y=1`，损失为  
   `Loss = -log(p) ≈ -log(0.1824) ≈ 1.701`

结论：模型认为正类概率很低，因此损失较大。

### 例题 2：为什么逻辑回归分不开 XOR？

**题目：**  
为什么 Logistic Regression 难以直接处理 XOR 这类经典非线性可分问题？

**答案要点：**

- Logistic Regression 的决策边界本质是线性的。
- XOR 数据不能被一条直线分开。
- 所以需要：
  - 加入非线性特征变换
  - 或使用带隐藏层的神经网络

## 7. 本章速记

- Logistic Regression：分类模型
- `z = w^T x + b`
- `sigmoid(z) = 1 / (1 + e^(-z))`
- 输出：正类概率
- 损失：cross entropy
- likelihood 大好，cross entropy 小好
- 局限：只能线性分割
