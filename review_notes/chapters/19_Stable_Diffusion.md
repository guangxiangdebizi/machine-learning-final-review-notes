## 4. 高频知识点整理

### 4.1 扩散模型的基本思想

扩散模型分两部分：

#### 正向扩散

- 逐步给真实数据加噪声
- 最后变成近似纯噪声

#### 反向去噪

- 学习如何把噪声一步步还原成数据

训练好后，生成时就从随机噪声开始，反复去噪，得到样本。

### 4.2 Stable Diffusion 为什么“Stable”

这类模型常在**潜空间（latent space）**中工作：

- 先把图片压缩成更小的潜表示
- 在潜空间里做扩散 / 去噪
- 最后再解码回图片

好处：

- 计算量更低
- 生成速度更快
- 资源消耗更可控

### 4.3 Noise Predictor / U-Net 的作用

PPT 明确说：

- 核心网络通常就是 **noise predictor**
- 它也叫 denoising network / denoise module
- 但它**不是整个 Stable Diffusion 系统的全部**

它的任务是：

- 输入当前带噪潜变量
- 预测噪声或去噪方向
- 指导反向扩散过程

### 4.4 Stable Diffusion 的大致流程

1. 把图像编码成潜表示
2. 在潜空间逐步加噪训练
3. 训练 U-Net 学会预测噪声
4. 生成时从随机噪声开始
5. 反复去噪
6. 解码回图像

### 4.5 FID（了解）

PPT 中还出现了 Fréchet Distance 相关内容。  
复习时知道它是**评价生成图像分布与真实图像分布接近程度**的指标即可，不必深究推导。

## 5. 易混点 / 易错点

- Stable Diffusion 不是“直接在原图像空间一步出图”，而是常在潜空间中完成主要生成过程。
- U-Net / noise predictor 是核心组件，但不是整个系统全部。
- 正向扩散是加噪，生成时真正用的是反向去噪。

## 6. 关键例题

### 例题 1：说明 Stable Diffusion 生成流程

**题目：**  
请用步骤说明 Stable Diffusion 生成一张图的大致过程。

**答案要点：**

1. 从随机噪声开始。
2. 在潜空间中输入给 U-Net / noise predictor。
3. 网络预测当前噪声，应如何去掉一部分噪声。
4. 经过多步迭代，潜变量越来越像真实图像表示。
5. 最后用解码器把潜变量还原成图像。

### 例题 2：为什么要在潜空间做扩散？

**题目：**  
为什么 Stable Diffusion 更常在潜空间而不是原始像素空间做扩散？

**答案要点：**

- 潜表示维度更低，计算更省。
- 训练和采样速度更快。
- 可以在保留主要语义结构的同时减少直接处理超大图像的成本。

## 7. 本章速记

- 扩散模型：加噪训练，去噪生成
- Stable Diffusion：latent diffusion
- 核心网络：U-Net / noise predictor
- 生成流程：噪声 -> 多步去噪 -> 图像
