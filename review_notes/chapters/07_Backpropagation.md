## 3. 结合 PPT 必须掌握的内容

PPT 后半段给了一个非常典型的小型网络例题：

- 输入层：1 个输入 `x`
- 隐藏层：1 个神经元
- 输出层：1 个神经元
- 激活函数都为 sigmoid
- 给定 `x=1, y=1, w1=0.5, b1=0, w2=1.0, b2=0`
- 损失用二分类交叉熵

这说明考试重点不是“背定义”，而是：

- 会做前向传播
- 会写输出层梯度
- 会按链式法则往前推

## 4. 高频知识点整理

### 4.1 反向传播在做什么

本质：  
已知损失函数 `L`，求每个参数对 `L` 的影响，也就是梯度。

然后用这些梯度更新参数。

### 4.2 为什么能“从后往前算”

因为网络是一个复合函数：

`x -> hidden -> output -> loss`

根据链式法则，后面的量对前面的量有依赖关系，因此可以从 loss 开始，逐层往前传播梯度。

### 4.3 常见公式

#### 输出层

若输出层为 sigmoid，损失为二分类交叉熵，则：

`delta_out = y_hat - y`

然后：

- `dL/dw2 = delta_out * h`
- `dL/db2 = delta_out`

#### 隐藏层

若隐藏层也用 sigmoid：

`delta_hidden = delta_out * w2 * h * (1-h)`

于是：

- `dL/dw1 = delta_hidden * x`
- `dL/db1 = delta_hidden`

### 4.4 参数更新

求出梯度后，再做：

`w = w - eta * gradient`

所以整条链路是：

1. 前向传播求输出
2. 计算损失
3. 反向传播求梯度
4. 更新参数

## 5. 易混点 / 易错点

- 前向传播是从左到右，反向传播是从右到左。
- **梯度传播方向**和**参数更新方向**不是一回事：
  - 梯度本身是损失增大的方向
  - 更新时仍然是减去梯度
- 隐藏层梯度一定要乘上本层激活函数的导数。
- 如果前面很多层都用 sigmoid，梯度可能一层层变小，这和第 08 章的梯度消失联系紧密。

## 6. 关键例题

### 例题 1：PPT 同型反向传播计算题

**题目：**  
设有一个两层神经网络：

- 输入 `x=1`
- 目标输出 `y=1`
- `w1=0.5, b1=0`
- `w2=1.0, b2=0`
- 隐藏层与输出层激活函数都为 sigmoid
- 损失函数为二分类交叉熵

求：

1. 隐藏层输出 `h`
2. 网络输出 `y_hat`
3. `dL/dw2, dL/db2, dL/dw1, dL/db1`

**答案要点：**

1. 隐藏层：
   - `z1 = w1*x + b1 = 0.5`
   - `h = sigmoid(0.5) ≈ 0.6225`
2. 输出层：
   - `z2 = w2*h + b2 = 0.6225`
   - `y_hat = sigmoid(0.6225) ≈ 0.6508`
3. 输出层误差项：
   - `delta_out = y_hat - y ≈ -0.3492`
4. 输出层梯度：
   - `dL/dw2 = delta_out * h ≈ -0.2174`
   - `dL/db2 = delta_out ≈ -0.3492`
5. 隐藏层误差项：
   - `delta_hidden = delta_out * w2 * h * (1-h) ≈ -0.0821`
6. 隐藏层梯度：
   - `dL/dw1 = delta_hidden * x ≈ -0.0821`
   - `dL/db1 = delta_hidden ≈ -0.0821`

### 例题 2：为什么越靠前的层越容易训练困难？

**题目：**  
说明为什么在深层网络中，越靠近输入层的参数有时越难训练。

**答案要点：**

- 反向传播时，前层梯度要乘上后面很多层的导数。
- 如果这些导数大多小于 1，梯度会连乘后迅速缩小。
- 结果就是前面层几乎收不到有效更新信号。
- 这就是梯度消失问题。

## 7. 本章速记

- 反向传播 = 链式法则求梯度
- 先前向，再反向
- 输出层常见：`delta_out = y_hat - y`
- 隐藏层梯度 = 后层误差 * 权重 * 激活导数
- 考试重点：会按流程算，不要求背复杂推导
