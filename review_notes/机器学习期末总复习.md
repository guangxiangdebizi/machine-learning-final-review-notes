# 01 Introduction：机器学习基础框架

## 1. 老师点名重点

- 监督学习、半监督学习、无监督学习的概念必须清楚。
- 回归、二分类、多分类要会区分。
- 机器学习三大步骤必须掌握：
  1. 建立模型 / 假设函数
  2. 定义 loss function
  3. 用梯度下降优化
- 要理解 loss function 的含义。
- 要知道 regularization 的作用。
- 要理解 bias 与 variance。

## 2. 本章不考 / 低优先级

- 本章以概念理解为主，**无复杂公式推导要求**。

## 3. 结合 PPT 必须掌握的内容

PPT 开头强调：**机器学习就是“自动找函数”**。  
也就是：给定输入和期望输出，让机器自己找到一个合适的映射函数。

PPT 中给出的任务视角：

- **回归**：输出连续值
- **分类**：输出类别
- **生成**：输出文本、图像等内容

PPT 还强调了两件事：

1. 你要先告诉机器“想找什么功能的函数”——这就是**建模**。
2. 你要告诉机器“什么样算好”——这就是**损失函数**。

## 4. 高频知识点整理

### 4.1 监督学习、半监督学习、无监督学习

#### 监督学习 Supervised Learning

- 训练数据有输入 `x` 和标签 `y`
- 目标：学到 `f(x) -> y`
- 常见任务：
  - 回归
  - 分类

**例子：**

- 用房屋面积预测房价
- 用图片预测猫狗类别

#### 半监督学习 Semi-supervised Learning

- 训练数据里**只有少量样本有标签**
- 大量样本无标签
- 目标：利用未标注数据帮助提升模型

**例子：**

- 100 张已标注病理图像 + 5000 张未标注图像做分类

#### 无监督学习 Unsupervised Learning

- 训练数据**没有标签**
- 目标：发现数据内部结构、分布或表示

**例子：**

- 聚类
- 降维
- 词向量学习

### 4.2 回归、二分类、多分类

- **回归**：输出连续数值  
  例如：股价、转向角度、温度、购买概率评分
- **二分类**：输出两个类别之一  
  例如：垃圾邮件 / 非垃圾邮件
- **多分类**：输出多个类别之一  
  例如：手写数字 0-9 分类

### 4.3 机器学习三大步骤

#### Step 1：建立模型

- 先确定函数形式
- 例如：
  - 线性模型
  - Logistic Regression
  - 神经网络

#### Step 2：定义损失函数

- 损失函数衡量“预测有多差”
- 常见：
  - 回归：MSE
  - 分类：Cross Entropy

#### Step 3：梯度下降优化

- 不断调整参数，让 loss 变小
- 本质：沿着**负梯度方向**更新参数

### 4.4 正则化、Bias、Variance

#### 正则化 Regularization

作用：

- 限制模型过于复杂
- 减少对噪声的过拟合
- 提升泛化能力

可以简单理解为：  
**不让模型为了拟合训练集而把曲线拧得太“奇怪”。**

#### Bias

- 模型太简单
- 连大致趋势都学不好
- 对应 **underfitting**

#### Variance

- 模型太敏感
- 训练集拟合很好，测试集表现差
- 对应 **overfitting**

## 5. 易混点 / 易错点

- **监督学习 ≠ 分类。** 回归也属于监督学习。
- **半监督学习 ≠ 无监督学习。** 半监督仍然有少量标签。
- **loss 小**表示模型当前更好，不代表一定已经泛化最好。
- **正则化**不是让 loss 一定更小，而是让模型更稳、更不容易过拟合。
- **bias 大**和**variance 大**不是同一件事：
  - bias 大：模型太弱
  - variance 大：模型太灵活

## 6. 关键例题

### 例题 1：判断任务类型

**题目：**  
判断下列任务分别属于监督学习、半监督学习还是无监督学习，并说明理由：

1. 用历史房价数据预测未来房价
2. 只有 100 条带标签评论和 1 万条无标签评论，做情感分类
3. 把用户按消费习惯自动分群

**答案要点：**

1. 监督学习：有输入和真实房价标签，属于回归。
2. 半监督学习：标签很少，但任务目标仍是分类。
3. 无监督学习：没有标签，目标是发现群体结构。

### 例题 2：Bias 与 Variance 分析

**题目：**  
某模型在训练集和测试集上都表现很差；另一模型训练集表现很好但测试集很差。分别说明它们更可能是哪类问题，并给出改进思路。

**答案要点：**

- 第一种：更像 **bias 大 / 欠拟合**
  - 改进：用更强模型、增加特征、训练更久
- 第二种：更像 **variance 大 / 过拟合**
  - 改进：正则化、dropout、数据增强、早停、简化模型

## 7. 本章速记

- 机器学习：自动找函数
- 监督：有标签
- 半监督：少量标签 + 大量无标签
- 无监督：没标签
- 回归：连续输出
- 分类：离散类别输出
- 三步骤：模型 -> loss -> 梯度下降
- 正则化：防过拟合
- bias 大：欠拟合
- variance 大：过拟合

# 02 Regression：回归

## 1. 老师点名重点

- 回归任务的输出是什么必须清楚。
- 回归属于监督学习。
- 回归与分类的区别要会说。
- 结合课程前面内容，要理解正则化、bias、variance 在回归中的作用。

## 2. 本章不考 / 低优先级

- **不强调高阶复杂推导**，重点在任务理解和基本公式含义。

## 3. 结合 PPT 必须掌握的内容

PPT 明确指出：**Regression 的输出是一个标量（连续值）**。

PPT 中的例子包括：

- 明日指数
- 方向盘角度
- 购买可能性
- 健康值、重量、高度

这说明回归不是“只能预测一个数”，而是“输出是连续数值”的问题。

## 4. 高频知识点整理

### 4.1 回归的定义

回归任务就是：  
给定输入特征 `x`，预测一个连续输出 `y`。

常见形式：

`y_hat = w^T x + b`

其中：

- `x`：输入特征
- `w`：权重
- `b`：偏置
- `y_hat`：预测值

### 4.2 回归与分类的区别

#### 回归

- 输出连续值
- 常见损失：MSE、MAE

#### 分类

- 输出类别或类别概率
- 常见损失：Cross Entropy

### 4.3 损失函数

回归最常见的是**均方误差**：

`MSE = (1/n) * Σ (y_hat_i - y_i)^2`

含义：

- 预测越接近真实值，损失越小
- 偏差越大，平方惩罚越明显

### 4.4 正则化在回归中的作用

PPT 这一章其实已经把“正则化”和“曲线平滑”联系起来了。

直观理解：

- 正则项越强，模型越不容易出现剧烈波动
- 对噪声越不敏感
- 但过强会把真实规律也压平，导致欠拟合

常见写法：

`Loss = MSE + lambda * ||w||^2`

这里通常只惩罚 `w`，不惩罚 `b`。  
PPT 也强调了这个思想：偏置控制整体平移，权重更直接决定曲线复杂度。

### 4.5 Bias 与 Variance 在回归里的表现

#### Bias 大

- 曲线太简单
- 连总体趋势都学不好

#### Variance 大

- 曲线太“扭”
- 训练集拟合很细，但测试集误差大

PPT 里把它和多次抽样、不同实验结果变化联系起来，本质是在讲：

- 模型太简单 -> bias 问题
- 模型太复杂 -> variance 问题

## 5. 易混点 / 易错点

- “购买可能性”如果老师按课程表述当作连续评分，也可以放在回归语境下理解。
- 回归不等于只有一维输入；**输入可以高维，输出通常是连续标量或连续向量**。
- 正则化不是“万能降误差”，它是**牺牲部分拟合能力换泛化能力**。
- 测试误差大，不一定都是 variance 大；也可能是特征本身没信息。

## 6. 关键例题

### 例题 1：判断回归还是分类

**题目：**  
判断下列任务属于回归还是分类，并说明原因：

1. 根据房屋面积预测房价
2. 判断邮件是否为垃圾邮件
3. 根据病人指标预测未来血糖值
4. 根据图片判断数字是 0-9 中哪一个

**答案要点：**

1. 回归：输出房价，是连续值。
2. 分类：输出垃圾 / 非垃圾两类。
3. 回归：输出血糖值，是连续值。
4. 多分类：输出 10 个类别之一。

### 例题 2：正则化与过拟合

**题目：**  
某回归模型训练误差很低，但测试误差很高。若加入更强的 L2 正则化后，训练误差略升高、测试误差下降。说明发生了什么。

**答案要点：**

- 原模型出现了过拟合，variance 较大。
- 正则化抑制了过于复杂的参数取值，使模型更平滑。
- 训练误差升高是正常现象，因为模型自由度被限制了。
- 测试误差下降说明泛化能力提高。

## 7. 本章速记

- 回归：预测连续值
- 常见模型：线性回归
- 常见损失：MSE
- 正则化：让模型更平滑
- bias 大：欠拟合
- variance 大：过拟合

# 03 Gradient Descent：梯度下降

## 1. 老师点名重点

- 梯度下降的核心思想与过程必须会。
- 要知道参数是怎么“下降”的。
- SGD 原理要理解。
- 常见优化器的大致思想要知道。
- **做过的练习题要重点复习。**

## 2. 本章不考 / 低优先级

- **高阶数学理论推导不作为重点。**
- 重点是：会解释、会写更新公式、会做基础计算题。

## 3. 结合 PPT 必须掌握的内容

PPT 里的核心句子：

- **Gradient 是让 loss 增大的方向**
- 所以真正更新时要往 **负梯度方向**走
- 学习率要调
- 要画 loss 随迭代次数变化的图
- Feature Scaling 很重要
- SGD、Adagrad、RMSProp、Adam 都是常见优化改造

PPT 还给出了一道明确练习题：  
`L(w)=w^2+5w+6, eta=0.1, w0=2`，做 3 次普通梯度下降，答案是 `w3=-0.196`。

## 4. 高频知识点整理

### 4.1 梯度下降的基本思想

目标：最小化损失函数 `L(w)`。

更新公式：

`w_(t+1) = w_t - eta * dL/dw`

其中：

- `eta`：学习率
- `dL/dw`：当前点的梯度

为什么减号？

- 因为梯度指向 loss 增大的方向
- 我们要让 loss 变小，就要往反方向走

### 4.2 学习率的作用

#### 学习率太大

- 容易震荡
- 甚至越过最优点

#### 学习率太小

- 收敛很慢
- 训练效率低

PPT 的形象说法：

- 大步迈，先探索
- 小步踱，再细化

### 4.3 SGD

#### Batch Gradient Descent

- 每次用全部样本算梯度
- 稳定但慢

#### Stochastic Gradient Descent

- 每次只用一个样本更新
- 快，但噪声大

#### Mini-batch SGD

- 折中方案
- 实际最常用

### 4.4 Feature Scaling

PPT 强调了一个很实用的点：  
如果不同维度尺度差太大，梯度下降会走得很别扭。

原因：

- 某些维度变化很快
- 某些维度变化很慢
- 等高线会很狭长，更新路径来回震荡

常见处理：

- 标准化
- 归一化

### 4.5 常见优化器

#### SGDM（动量）

- 引入历史梯度信息
- 减少来回摆动
- 有助于冲出平缓区或局部困境

#### Adagrad

- 对不同参数自适应调整步长
- 历史梯度大的方向，后续步长会变小
- 缺点：后期步长可能衰减过快

#### RMSProp

- 改进 Adagrad
- 用指数加权方式估计梯度平方
- 缓解步长过快衰减

#### Adam

- 动量 + RMSProp 的结合
- 工程上常用
- 收敛快、较稳

## 5. 易混点 / 易错点

- 梯度是“增大最快方向”，**不是最小方向**。
- “梯度为 0”不一定是全局最优，也可能是鞍点或局部点。
- SGD 并不是一定比 Batch 更差；它虽然有噪声，但常常更快。
- Feature Scaling 不是改变任务本身，而是让优化更顺畅。
- Adam、RMSProp 是优化技巧，不是新的损失函数。

## 6. 关键例题

### 例题 1：普通梯度下降计算题

**题目：**  
已知损失函数

`L(w)=w^2+5w+6`

学习率 `eta=0.1`，初始值 `w0=2`。  
用普通梯度下降法计算 3 次迭代后的参数值。

**答案要点：**

1. 求导：`dL/dw = 2w + 5`
2. 更新公式：`w_new = w_old - 0.1*(2w_old+5)`
3. 计算：
   - `w1 = 2 - 0.1*(9) = 1.1`
   - `w2 = 1.1 - 0.1*(7.2) = 0.38`
   - `w3 = 0.38 - 0.1*(5.76) = -0.196`

**最终答案：** `w3 = -0.196`

### 例题 2：为什么要做 Feature Scaling？

**题目：**  
某模型两个特征分别是“年收入（万元）”和“年龄（岁）”，前者数值范围远大于后者。若直接做梯度下降，为什么可能训练很慢？如何改进？

**答案要点：**

- 不同特征尺度差异会让损失面的等高线很狭长。
- 梯度下降会在某一方向上大幅震荡，在另一方向上缓慢前进。
- 会导致收敛慢、学习率难调。
- 解决方法：标准化 / 归一化 / whitening 等尺度处理。

## 7. 本章速记

- 梯度：loss 增大最快方向
- 更新：负梯度方向
- 学习率太大：震荡
- 学习率太小：太慢
- SGD：快但有噪声
- Feature Scaling：让优化更好走
- Adam：动量 + 自适应学习率

# 04 Classification：分类

## 1. 老师点名重点

- 分类问题的输入与输出必须清楚。
- 分类基本框架要理解。
- 最大似然（Maximum Likelihood）概念必须理解。
- 要会解释“似然越大说明什么”。

## 2. 本章不考 / 低优先级

- **高斯分布复杂内容不考。**
- **最大似然数学推导不考。**

## 3. 结合 PPT 必须掌握的内容

PPT 这章用了宝可梦向量表示的例子，本质是在说明：

- 输入通常是一个特征向量
- 输出是某个类别
- 模型要根据输入向量判断“它属于哪一类”

PPT 还提到：

- loss 可以理解为错误数或分类错误程度
- 先验、最大似然、朴素贝叶斯这些概念在分类里常出现
- 一般会假设某些统计量（如 covariance）共享，但**考试不要求复杂推导**

## 4. 高频知识点整理

### 4.1 分类任务是什么

分类任务是：  
给定输入 `x`，输出所属类别 `y`。

输出形式可能是：

- 直接输出类别编号
- 输出每个类别的概率，再取最大者

### 4.2 二分类与多分类

#### 二分类

- 只有两类
- 例如：是 / 否，正 / 负

#### 多分类

- 类别数大于 2
- 例如：0-9 手写数字分类

### 4.3 最大似然的直观理解

最大似然不是在问“参数本身像不像真的”，而是在问：

> 哪组参数能让我们已经观察到的数据“最有可能出现”？

所以：

- **似然越大**：说明当前模型参数更能解释观测数据
- **似然越小**：说明这组参数不太能解释这些数据

### 4.4 分类的一般流程

1. 把样本表示成特征向量
2. 选择模型
3. 计算每类得分或概率
4. 选概率最大的类别
5. 用损失函数训练参数

### 4.5 朴素贝叶斯（概念层面）

PPT 提到朴素贝叶斯，考试更可能考**思想**而不是推导：

- 利用贝叶斯思想做分类
- 假设特征之间条件独立
- 计算每个类别下样本出现的可能性

## 5. 易混点 / 易错点

- **最大似然**和**后验概率最大**不是完全同一个概念。
- 分类输出是**类别 / 类别概率**，不是连续数值本身。
- 分类可以用线性边界，也可以用更复杂边界。
- 这章老师说高斯推导不考，不代表“最大似然”概念可以不懂。

## 6. 关键例题

### 例题 1：解释最大似然

**题目：**  
用一句尽量口语化的话解释“最大似然”是什么意思。

**答案要点：**

可以答成：

> 在很多可能的模型参数里，选那组最能解释当前观测数据、最能让这些数据出现的参数。

如果展开说：

- 已经看到了这批数据
- 比较不同参数下“这批数据出现的概率”
- 谁更大就更合理

### 例题 2：分类 vs 回归

**题目：**  
“根据学生成绩预测他属于优秀、良好、及格、不及格中的哪一类”是回归还是分类？  
“根据学生平时表现预测最终分数”又是什么？

**答案要点：**

- 前者是分类：输出是有限个离散等级
- 后者是回归：输出是连续分数

## 7. 本章速记

- 分类：输出类别
- 二分类：两类
- 多分类：多类
- 最大似然：选最能解释数据的参数
- 朴素贝叶斯：用概率做分类，强调条件独立假设

# 05 Logistic Regression：逻辑回归

## 1. 老师点名重点

- Logistic Regression 原理必须理解。
- 激活函数的概念要懂。
- 机器学习三步骤在逻辑回归中的体现要会说。
- sigmoid 等函数的基本形式要理解。

## 2. 本章不考 / 低优先级

- **不考复杂数学推导。**
- 重点是：模型结构、概率解释、loss、线性可分限制。

## 3. 结合 PPT 必须掌握的内容

PPT 明确给出的关键信息：

- `L` 是 likelihood，**越大越好**
- 训练时会把它转成要最小化的量
- 各训练样本上的 **cross entropy 求和**
- Logistic Regression 只能做**线性分割**
- 若线性分不开，就要考虑特征变换或更复杂模型

## 4. 高频知识点整理

### 4.1 Logistic Regression 做什么

它本质上是一个**分类模型**，尤其适合二分类。

基本形式：

1. 先做线性变换  
   `z = w^T x + b`
2. 再过 sigmoid  
   `p = sigmoid(z) = 1 / (1 + e^(-z))`

其中：

- `p` 可以理解为样本属于正类的概率

### 4.2 为什么要用 sigmoid

线性输出 `z` 的取值范围是整个实数轴。  
sigmoid 可以把它压到 `(0,1)` 区间，便于解释成概率。

特点：

- `z` 越大，`p` 越接近 1
- `z` 越小，`p` 越接近 0

### 4.3 机器学习三步骤在逻辑回归中的体现

#### Step 1：模型

`p(y=1|x) = sigmoid(w^T x + b)`

#### Step 2：损失函数

通常使用交叉熵损失：

`Loss = -[ y log p + (1-y) log(1-p) ]`

多样本时，对所有样本求和或求平均。

#### Step 3：优化

- 对 loss 求梯度
- 用梯度下降或 Adam 等方法更新参数

### 4.4 likelihood 与 cross entropy 的关系

PPT 已经给出直观关系：

- likelihood 越大越好
- 但训练更常做的是最小化损失

所以通常把“最大化 likelihood”改写成：

- 最小化负对数似然
- 也就是常见的 cross entropy

### 4.5 逻辑回归的局限

PPT 明确指出：

- Logistic Regression 只能做**线性分割**

所以如果数据天然是非线性可分的：

- 可以做特征变换
- 或直接换成更强模型（如神经网络）

## 5. 易混点 / 易错点

- 逻辑回归虽然名字里有“回归”，但它主要用于**分类**。
- sigmoid 是激活函数，不是损失函数。
- likelihood 越大越好；cross entropy 越小越好。
- 逻辑回归输出的是概率，不是已经离散化后的类别编号。
- softmax 常用于多分类，sigmoid 更典型用于二分类。

## 6. 关键例题

### 例题 1：手算一次 Logistic 输出与损失

**题目：**  
设 `x=[1,2]`，`w=[0.5,-1]`，`b=0`，真实标签 `y=1`。  
求：

1. 线性输出 `z`
2. 概率 `p`
3. 单样本交叉熵损失

**答案要点：**

1. `z = 0.5*1 + (-1)*2 = -1.5`
2. `p = sigmoid(-1.5) ≈ 0.1824`
3. 因为 `y=1`，损失为  
   `Loss = -log(p) ≈ -log(0.1824) ≈ 1.701`

结论：模型认为正类概率很低，因此损失较大。

### 例题 2：为什么逻辑回归分不开 XOR？

**题目：**  
为什么 Logistic Regression 难以直接处理 XOR 这类经典非线性可分问题？

**答案要点：**

- Logistic Regression 的决策边界本质是线性的。
- XOR 数据不能被一条直线分开。
- 所以需要：
  - 加入非线性特征变换
  - 或使用带隐藏层的神经网络

## 7. 本章速记

- Logistic Regression：分类模型
- `z = w^T x + b`
- `sigmoid(z) = 1 / (1 + e^(-z))`
- 输出：正类概率
- 损失：cross entropy
- likelihood 大好，cross entropy 小好
- 局限：只能线性分割

# 06 Deep Learning：深度学习

## 1. 老师点名重点

- **前向传播必须会算。**
- 要会：
  - 权重怎么乘
  - bias 怎么加
  - 激活函数怎么算
- ReLU、Sigmoid 公式要记住。
- 反向传播基本链路要理解。
- 可能有计算题，允许用计算器。

## 2. 本章不考 / 低优先级

- **复杂推导不是重点**。
- 重点是：网络结构理解、前向传播手算、激活函数理解。

## 3. 结合 PPT 必须掌握的内容

PPT 这章给出的核心信息：

- 神经网络是一连串 **Matrix Operation**
- 输入可以是高维，比如 `Input 256 维`
- 输出可以是分类结果，比如 `Output 10 维`
- 需要自己设计：
  - 有多少层 layer
  - 每层多少个 neuron
- 新样本到来后，参数会在原有基础上继续更新

这说明深度学习就是：  
**用多层线性变换 + 非线性激活，逐层提取更复杂特征。**

## 4. 高频知识点整理

### 4.1 神经网络的基本结构

一个典型前馈神经网络包含：

- 输入层
- 若干隐藏层
- 输出层

每一层都做两件事：

1. 线性变换  
   `z^(l) = W^(l) a^(l-1) + b^(l)`
2. 非线性激活  
   `a^(l) = f(z^(l))`

### 4.2 为什么要“深”

如果只有线性层叠加而没有激活函数，那么多层线性变换仍然等价于一层线性变换。  
真正让模型表达能力变强的是：

- 多层结构
- 非线性激活函数

### 4.3 常见激活函数

#### Sigmoid

`sigmoid(z) = 1 / (1 + e^(-z))`

特点：

- 输出范围在 `(0,1)`
- 常用于概率解释
- 但深层网络里容易引起梯度变小

#### ReLU

`ReLU(z) = max(0, z)`

特点：

- 计算简单
- 梯度传播更稳定
- 负区间可能出现“死亡 ReLU”

### 4.4 前向传播的本质

从输入层开始，逐层做：

- 加权求和
- 加偏置
- 过激活函数

直到得到最终输出。

考试里常见要求：

- 给一张小网络图
- 让你从左往右算到输出

## 5. 易混点 / 易错点

- **先乘权重再加 bias，再过激活函数**，顺序不要写反。
- 多层网络不是“层数越多越好”，太深可能更难训练。
- 输出层激活函数要看任务：
  - 二分类常用 sigmoid
  - 多分类常用 softmax
  - 回归输出层有时直接线性输出
- 神经网络的“深”不是指数据维度大，而是层数多。

## 6. 关键例题

### 例题 1：前向传播手算

**题目：**  
设输入 `x=[1,2]^T`，隐藏层有 2 个神经元：

- `W1 = [[1,0],[-1,1]]`
- `b1 = [0,1]^T`
- 隐藏层激活函数为 ReLU

输出层：

- `W2 = [0.5,-1]`
- `b2 = 0`
- 输出层激活函数为 sigmoid

求网络最终输出。

**答案要点：**

1. 隐藏层线性输出：
   - 第 1 个神经元：`1*1 + 0*2 + 0 = 1`
   - 第 2 个神经元：`-1*1 + 1*2 + 1 = 2`
2. 过 ReLU：
   - `a1 = [1,2]^T`
3. 输出层线性输出：
   - `z2 = 0.5*1 + (-1)*2 = -1.5`
4. 最终输出：
   - `y_hat = sigmoid(-1.5) ≈ 0.1824`

### 例题 2：为什么激活函数不能省？

**题目：**  
为什么神经网络如果每层都不加激活函数，表达能力会大幅下降？

**答案要点：**

- 因为多层线性变换复合后仍然是线性变换。
- 没有非线性，网络就无法表达复杂非线性关系。
- 所以深度学习的关键不是只有“很多层”，而是“很多层 + 非线性”。

## 7. 本章速记

- 神经网络 = 多层线性变换 + 激活函数
- 前向传播：乘权重 -> 加偏置 -> 过激活
- `z = Wx + b`
- Sigmoid：压到 `(0,1)`
- ReLU：`max(0,z)`
- 考试高频：手算前向传播

# 07 Backpropagation：反向传播

## 1. 老师点名重点

- 反向传播完整流程必须理解。
- 要结合例题掌握梯度是怎么从后往前传的。
- 前向传播 + 反向传播要连成一条完整链路。

## 2. 本章不考 / 低优先级

- 老师明确说：**不会考原题**。
- 但会考同类结构的“换形式题”。

## 3. 结合 PPT 必须掌握的内容

PPT 后半段给了一个非常典型的小型网络例题：

- 输入层：1 个输入 `x`
- 隐藏层：1 个神经元
- 输出层：1 个神经元
- 激活函数都为 sigmoid
- 给定 `x=1, y=1, w1=0.5, b1=0, w2=1.0, b2=0`
- 损失用二分类交叉熵

这说明考试重点不是“背定义”，而是：

- 会做前向传播
- 会写输出层梯度
- 会按链式法则往前推

## 4. 高频知识点整理

### 4.1 反向传播在做什么

本质：  
已知损失函数 `L`，求每个参数对 `L` 的影响，也就是梯度。

然后用这些梯度更新参数。

### 4.2 为什么能“从后往前算”

因为网络是一个复合函数：

`x -> hidden -> output -> loss`

根据链式法则，后面的量对前面的量有依赖关系，因此可以从 loss 开始，逐层往前传播梯度。

### 4.3 常见公式

#### 输出层

若输出层为 sigmoid，损失为二分类交叉熵，则：

`delta_out = y_hat - y`

然后：

- `dL/dw2 = delta_out * h`
- `dL/db2 = delta_out`

#### 隐藏层

若隐藏层也用 sigmoid：

`delta_hidden = delta_out * w2 * h * (1-h)`

于是：

- `dL/dw1 = delta_hidden * x`
- `dL/db1 = delta_hidden`

### 4.4 参数更新

求出梯度后，再做：

`w = w - eta * gradient`

所以整条链路是：

1. 前向传播求输出
2. 计算损失
3. 反向传播求梯度
4. 更新参数

## 5. 易混点 / 易错点

- 前向传播是从左到右，反向传播是从右到左。
- **梯度传播方向**和**参数更新方向**不是一回事：
  - 梯度本身是损失增大的方向
  - 更新时仍然是减去梯度
- 隐藏层梯度一定要乘上本层激活函数的导数。
- 如果前面很多层都用 sigmoid，梯度可能一层层变小，这和第 08 章的梯度消失联系紧密。

## 6. 关键例题

### 例题 1：PPT 同型反向传播计算题

**题目：**  
设有一个两层神经网络：

- 输入 `x=1`
- 目标输出 `y=1`
- `w1=0.5, b1=0`
- `w2=1.0, b2=0`
- 隐藏层与输出层激活函数都为 sigmoid
- 损失函数为二分类交叉熵

求：

1. 隐藏层输出 `h`
2. 网络输出 `y_hat`
3. `dL/dw2, dL/db2, dL/dw1, dL/db1`

**答案要点：**

1. 隐藏层：
   - `z1 = w1*x + b1 = 0.5`
   - `h = sigmoid(0.5) ≈ 0.6225`
2. 输出层：
   - `z2 = w2*h + b2 = 0.6225`
   - `y_hat = sigmoid(0.6225) ≈ 0.6508`
3. 输出层误差项：
   - `delta_out = y_hat - y ≈ -0.3492`
4. 输出层梯度：
   - `dL/dw2 = delta_out * h ≈ -0.2174`
   - `dL/db2 = delta_out ≈ -0.3492`
5. 隐藏层误差项：
   - `delta_hidden = delta_out * w2 * h * (1-h) ≈ -0.0821`
6. 隐藏层梯度：
   - `dL/dw1 = delta_hidden * x ≈ -0.0821`
   - `dL/db1 = delta_hidden ≈ -0.0821`

### 例题 2：为什么越靠前的层越容易训练困难？

**题目：**  
说明为什么在深层网络中，越靠近输入层的参数有时越难训练。

**答案要点：**

- 反向传播时，前层梯度要乘上后面很多层的导数。
- 如果这些导数大多小于 1，梯度会连乘后迅速缩小。
- 结果就是前面层几乎收不到有效更新信号。
- 这就是梯度消失问题。

## 7. 本章速记

- 反向传播 = 链式法则求梯度
- 先前向，再反向
- 输出层常见：`delta_out = y_hat - y`
- 隐藏层梯度 = 后层误差 * 权重 * 激活导数
- 考试重点：会按流程算，不要求背复杂推导

# 08 Tips for Deep Learning：深度学习技巧

## 1. 老师点名重点

- 激活函数公式要记住：
  - ReLU
  - Sigmoid
- 前向传播 + 反向传播整体逻辑要熟。
- 常见基础技巧要理解，不要求死记推导。

## 2. 本章不考 / 低优先级

- 复杂理论推导不作为重点。
- 但这章经常会出**概念辨析题、简答题**。

## 3. 结合 PPT 必须掌握的内容

PPT 这章覆盖的高频技巧包括：

- 局部最优 / 训练困难
- 梯度消失
- ReLU、Leaky ReLU、Maxout 等激活函数
- RMSProp、Adam 等优化器
- 正则化
- dropout

所以这一章其实是在回答一个问题：

> 神经网络为什么不好训？又该怎么训得更稳？

## 4. 高频知识点整理

### 4.1 梯度消失

PPT 强调：  
如果层数很深，且激活函数像 sigmoid 这样导数经常比较小，那么梯度会一层层衰减。

后果：

- 越靠前的层越难学到东西
- 网络训练慢
- 有时几乎不更新

### 4.2 ReLU 与变体

#### ReLU

`ReLU(x) = max(0, x)`

优点：

- 简单
- 梯度传播通常比 sigmoid 更好

缺点：

- 负区间梯度为 0，可能出现“死亡神经元”

#### Leaky ReLU

- 在负区间保留一个很小斜率
- 目的是让负半轴也有一点梯度

#### Maxout

- 用多个线性函数的最大值作为输出
- 表达能力更强，但参数更多

### 4.3 Dropout

PPT 里把 dropout 讲得很形象：  
训练时随机“去掉一部分连接 / 神经元”，相当于在训练许多不同子网络。

作用：

- 减少过拟合
- 提高泛化能力

测试时：

- 不再随机丢
- 使用完整网络并做相应缩放

### 4.4 RMSProp 与 Adam

#### RMSProp

- 用最近梯度平方的滑动平均来调步长
- 缓解不同方向更新不均衡问题

#### Adam

- 动量 + 自适应学习率
- 工程上非常常见

### 4.5 正则化与权重衰减

PPT 也强调了一个常见现象：

- 权重衰减会把参数往小的方向拉
- 这有助于防止模型过于复杂

本质上仍然是在做泛化控制。

## 5. 易混点 / 易错点

- **局部最优**和**梯度消失**不是一回事：
  - 局部最优：优化地形问题
  - 梯度消失：梯度传不回来
- ReLU 不是永远优于 sigmoid；要看任务位置和输出解释。
- dropout 只在训练时随机失活，测试时不是继续随机扔掉。
- Adam 是优化器，不是激活函数。

## 6. 关键例题

### 例题 1：为什么深层网络常用 ReLU？

**题目：**  
与 sigmoid 相比，为什么在隐藏层中更常使用 ReLU？

**答案要点：**

- sigmoid 在绝对值较大时导数很小，容易导致梯度消失。
- ReLU 在正区间导数为 1，梯度更容易传播。
- ReLU 计算量也更小。
- 但 ReLU 也可能出现死亡神经元，因此有时会改成 Leaky ReLU。

### 例题 2：dropout 的作用是什么？

**题目：**  
请解释 dropout 为什么能缓解过拟合。

**答案要点：**

- 训练时随机去掉部分神经元或连接。
- 模型不能过度依赖某一条固定路径。
- 相当于训练了许多共享参数的子网络并做集成。
- 因此泛化能力通常更好。

## 7. 本章速记

- 深层网络难训：局部最优、梯度消失、过拟合
- Sigmoid：概率感强，但深层易梯度消失
- ReLU：简单有效
- Leaky ReLU：负半轴保留小梯度
- Dropout：随机失活，防过拟合
- Adam：最常见优化器之一

# 09 Semi-supervised Learning：半监督学习

## 1. 老师点名重点

- 半监督学习概念必须清楚。
- 要能和监督 / 无监督区分。
- 最好能举例说明。

## 2. 本章不考 / 低优先级

- 无特殊复杂公式要求。
- 重点在概念、假设、典型思路。

## 3. 结合 PPT 必须掌握的内容

PPT 明确出现了这些关键字：

- 传导学习
- 归纳学习
- Smoothness Assumption
- “近朱者赤，近墨者黑”
- 高密度路径
- GRBF / 相似度

这说明老师希望你理解：

> 未标注数据为什么能帮上忙？

## 4. 高频知识点整理

### 4.1 什么是半监督学习

半监督学习指：

- 有少量带标签数据
- 有大量无标签数据
- 目标仍然是做好监督任务（分类 / 回归）

### 4.2 为什么无标签数据能帮忙

关键前提：**数据分布有结构**。

如果数据天然形成簇、流形或高密度区域，那么无标签数据能告诉模型：

- 哪些点彼此接近
- 哪些点更可能属于同一类

### 4.3 Smoothness Assumption

这条是本章最核心思想：

> 如果两个点在数据流形上接近，尤其通过高密度路径连接，那么它们更可能有相同标签。

PPT 里特别提醒：

- 两点欧氏距离近，不一定同类
- 如果中间没有高密度路径，仍可能不同类

### 4.4 传导学习 vs 归纳学习

#### 传导学习

- 目标是把现有未标注样本标好
- 更关注当前这批无标签数据本身

#### 归纳学习

- 学到一个可泛化到未来新样本的模型
- 更像通常意义上的训练预测器

### 4.5 图方法与相似度

PPT 提到用相似度来表达点与点之间的关系。  
常见形式可以写成：

`S_ij = exp(-alpha * ||x_i - x_j||^2)`

作用：

- 近点相似度高
- 远点相似度低
- 便于构造图和传播标签

## 5. 易混点 / 易错点

- 半监督学习仍然是“有标签任务”，不是无监督。
- “点离得近”不等于一定同类，还要考虑是否有高密度连通路径。
- 传导学习与归纳学习都能用半监督思想，但目标不同。

## 6. 关键例题

### 例题 1：高密度路径判断题

**题目：**  
已知 `x1` 和 `x2` 之间有连续高密度样本带连接，`x2` 和 `x3` 欧氏距离更近，但中间几乎没有样本。根据 Smoothness Assumption，哪一对更可能同类？

**答案要点：**

- 更可能同类的是 `x1` 和 `x2`。
- 因为半监督学习强调的不只是“几何距离近”，还强调“高密度路径连通”。

### 例题 2：半监督学习举例

**题目：**  
请举一个适合使用半监督学习的真实场景，并说明为什么不用纯监督或纯无监督。

**答案要点：**

例如医学影像分类：

- 带标签数据很少，因为医生标注成本高
- 无标签数据很多，因为机器采集容易
- 纯监督会浪费大量无标签样本
- 纯无监督又无法直接对接分类目标

## 7. 本章速记

- 半监督：少量标签 + 大量无标签
- 核心问题：无标签数据如何帮监督任务
- 关键假设：Smoothness / 高密度路径
- 传导：给当前无标签样本贴标签
- 归纳：学可泛化模型

# 10 Un-supervised Learning：无监督学习

## 1. 老师点名重点

- 无监督学习概念要清楚。
- 要能和监督 / 半监督区分。
- 基本应用要理解。

## 2. 本章不考 / 低优先级

- 无明确复杂公式要求。
- 本章更偏概念题和应用理解题。

## 3. 结合 PPT 必须掌握的内容

PPT 这章标题里直接带了 **Word Embedding**，还强调了：

- 同一个词在不同位置如果共享参数，可以得到一致表示
- bag-of-words 没有考虑词序

说明本章不仅讲“无监督是什么”，还在用**词向量**当作代表例子。

## 4. 高频知识点整理

### 4.1 什么是无监督学习

无监督学习指：

- 数据没有标签
- 模型从数据中自动发现结构、模式或表示

典型任务：

- 聚类
- 降维
- 表示学习
- 词向量学习

### 4.2 无监督学习和监督学习的区别

#### 监督学习

- 有标签
- 目标明确：预测标签

#### 无监督学习

- 没有标签
- 目标是发现数据内部关系

### 4.3 Word Embedding 的直观理解

词向量的目标是：

- 给每个词学一个连续向量表示
- 让语义接近的词在向量空间里也更接近

好处：

- 比 one-hot 更紧凑
- 能表达词与词之间的语义关系

### 4.4 参数共享的意义

PPT 提到：

- 同一个词出现在不同位置，如果共享权重，则它的表示更一致
- 同时还能减少参数量

这是深度学习 / NLP 中非常重要的思想。

### 4.5 Bag-of-Words 的局限

PPT 明说：bag-of-words **没有考虑词序**。

所以它的缺点是：

- 句子中词的排列关系丢失
- “我打你”和“你打我”在 BoW 下可能非常像

## 5. 易混点 / 易错点

- 无监督不等于“什么都学不到”，它能学到结构和表示。
- 词向量学习虽然最后会服务于监督任务，但训练词向量本身常常可以是无监督 / 自监督式的。
- bag-of-words 简单但表达力有限，不能理解顺序关系。

## 6. 关键例题

### 例题 1：为什么词向量比 one-hot 更有用？

**题目：**  
说明词向量相较 one-hot 表示的两个主要优势。

**答案要点：**

1. 维度通常更低，更紧凑。
2. 能表达词之间的相似关系，而 one-hot 彼此几乎正交，看不出语义接近性。

### 例题 2：Bag-of-Words 的问题

**题目：**  
为什么说 bag-of-words 不适合精确表达句子语义？

**答案要点：**

- 它只统计词出现了没有 / 出现多少次。
- 不记录词序。
- 因此许多语义不同但词集合相近的句子会被表示得很像。

## 7. 本章速记

- 无监督：没有标签
- 目标：发现结构 / 表示
- 典型例子：聚类、降维、词向量
- Word Embedding：学词的连续向量
- Bag-of-Words：简单，但不看词序

# 11 Explainable / Interpretable ML：可解释机器学习

## 1. 老师点名重点

- 概念理解即可。
- 重点是知道：**为什么需要可解释性**。

## 2. 本章不考 / 低优先级

- 老师明确说：**不作为重点章节**。
- 但可能以概念题、开放题出现。

## 3. 结合 PPT 必须掌握的内容

PPT 里给出的典型问题非常有代表性：

- 招聘筛选时，模型到底看的是能力还是性别？
- 犯罪评估时，模型到底看的是证据还是肤色？
- 金融拒贷为什么要给理由？
- 模型诊断为什么不能只看正确率？

所以这章最核心的问题是：

> 模型做出了一个决定，我们能不能说明“它为什么这么做”？

## 4. 高频知识点整理

### 4.1 什么是可解释 / 可理解

#### Interpretable

- 模型结构本身就比较容易理解
- 例如：浅层决策树、线性模型

#### Explainable

- 模型本身可能很复杂
- 但可以借助其他方法对它的行为做解释

### 4.2 为什么要解释模型

主要原因有三类：

1. **公平性 / 合规性**
   - 决策不能带来不合理歧视
2. **可追责**
   - 重要决策要能说明理由
3. **模型诊断**
   - 发现模型到底学到了什么、有没有学偏

### 4.3 常见解释视角

#### 全局解释 Global Explanation

- 解释整个模型总体在干什么

#### 局部解释 Local Explanation

- 解释某一个具体样本为什么被这样判断

### 4.4 常见方法（理解层面）

- 显著性图 / saliency
- 扰动法 / perturbation
- 用简单模型去模仿复杂模型（surrogate model）

## 5. 易混点 / 易错点

- “模型准确率高”不代表“模型可信”。
- 可解释性不是只给开发者看的，在金融、医疗、司法里尤其重要。
- 可解释不一定要求模型本身简单，也可以是“复杂模型 + 解释工具”。

## 6. 关键例题

### 例题：为什么不能只看准确率？

**题目：**  
一个模型在贷款审批任务上准确率很高，为什么还需要研究它的可解释性？

**答案要点：**

- 因为它可能学到了不应依赖的特征，例如性别、种族、无关背景。
- 金融决策往往需要给用户说明拒绝原因。
- 只有知道模型为什么这么判，才能发现偏见和错误规则。

## 7. 本章速记

- 可解释性：解释模型为什么这么判
- 原因：公平、合规、诊断
- 全局解释：解释整体
- 局部解释：解释单个样本
- 这章不是重点，但概念题容易出

# 12 Attack and Defense：攻击与防御

## 1. 老师点名重点

- 经典攻击方法要会，尤其是 **FGSM**。
- 要理解攻击与防御的基本思想。
- 这章容易出“经典而简单”的算法题 / 简答题。

## 2. 本章不考 / 低优先级

- 未强调复杂理论推导。
- 重点是：基本概念、基本公式、基本流程。

## 3. 结合 PPT 必须掌握的内容

PPT 这章强调了几件事：

- 攻击希望**不被发现**
- `L-infinity` 范数常用于描述扰动约束
- 用了 **gradient attack** 的方式
- 防御里提到了**平滑化**
- 还提到了“并修补，让模型同时学会哪些是不好的”，对应对抗训练思路

## 4. 高频知识点整理

### 4.1 对抗攻击是什么

对抗攻击是指：

- 对输入做很小扰动
- 人看起来差不多
- 但模型预测会明显出错

目标：

- 骗过模型
- 尽量不被人察觉

### 4.2 为什么常用 `L-infinity`

`L-infinity` 约束的是：

> 每个维度上允许改动的最大幅度

适合理解成：

- 每个像素最多改多少
- 保证整体改动“不明显”

### 4.3 FGSM（Fast Gradient Sign Method）

这是最经典、最容易考的攻击算法。

公式：

`x_adv = x + epsilon * sign(grad_x L(theta, x, y))`

含义：

1. 先求损失对输入的梯度
2. 取梯度符号
3. 按 `epsilon` 大小朝着“让损失增大”的方向改输入

特点：

- 快
- 简单
- 一步法

### 4.4 常见防御思路

#### 平滑化 / 去噪

- 让输入或模型决策更平滑
- 降低小扰动引起的大变化

#### 对抗训练

- 训练时把对抗样本也加入
- 让模型知道“哪些扰动是坏的”
- 提升鲁棒性

## 5. 易混点 / 易错点

- FGSM 改的是**输入**，不是直接改模型参数。
- `epsilon` 越大，攻击通常越强，但也越容易被察觉。
- 对抗鲁棒性和普通准确率不完全是同一件事。
- 防御不是简单“把准确率做高”，而是让模型对扰动更不敏感。

## 6. 关键例题

### 例题 1：FGSM 手算题

**题目：**  
设原始输入 `x=[0.4, 0.6, 0.2]`，`epsilon=0.1`，  
已知损失对输入的梯度为 `grad_x L = [0.2, -1.5, 0]`。  
用 FGSM 生成对抗样本。

**答案要点：**

1. 先取符号：
   - `sign(grad_x L) = [1, -1, 0]`
2. 套公式：
   - `x_adv = x + 0.1 * [1, -1, 0]`
3. 得到：
   - `x_adv = [0.5, 0.5, 0.2]`

### 例题 2：为什么对抗训练有效？

**题目：**  
简述为什么把对抗样本加入训练集可以提升鲁棒性。

**答案要点：**

- 模型在训练时就见过“恶意扰动”的样本。
- 它会学到在这些方向上不要轻易改变预测。
- 因此对输入小扰动更稳健。

## 7. 本章速记

- 对抗攻击：小改动，大误判
- 目标：骗模型且尽量不被发现
- `L-infinity`：限制单维最大改动
- FGSM：沿输入梯度符号方向加扰动
- 防御：平滑化、对抗训练

# 13 Network Compression：模型压缩

## 1. 老师点名重点

- 基本概念了解即可。

## 2. 本章不考 / 低优先级

- 老师明确说：**不作为重点章节**。
- 复习时知道几个典型方向即可。

## 3. 结合 PPT 必须掌握的内容

PPT 提到了几条主线：

- Network Pruning
- Knowledge Distillation
- Parameter Quantization
- Architecture Design
- Dynamic Computation

这说明这章不要求你深挖推导，而是知道：

> 怎么让模型更小、更快、更省资源。

## 4. 高频知识点整理

### 4.1 为什么要压缩模型

目标：

- 降低模型体积
- 降低推理延迟
- 降低显存 / 存储 / 能耗

### 4.2 常见压缩方法

#### 剪枝 Pruning

- 去掉不重要的权重、连接或通道

#### 知识蒸馏 Distillation

- 用大模型教小模型
- 让小模型学到大模型的输出分布或中间知识

#### 量化 Quantization

- 用更低位数表示参数
- 如从 32 位浮点降到 8 位甚至更低

#### 结构设计

- 直接设计更轻量的网络结构

#### 动态计算

- 不同样本走不同计算路径
- 节省平均计算量

## 5. 易混点 / 易错点

- 压缩不是只删参数，蒸馏和量化也很重要。
- 小模型不一定更容易训练，PPT 也提醒了这一点。
- “模型小”与“精度一定低”不是绝对关系，关键看压缩方式。

## 6. 关键例题

### 例题：三种压缩方法辨析

**题目：**  
比较剪枝、蒸馏、量化三种模型压缩方法的核心思路。

**答案要点：**

- 剪枝：删掉不重要参数或结构
- 蒸馏：让小模型模仿大模型
- 量化：降低参数表示精度

如果再展开：

- 剪枝偏结构稀疏化
- 蒸馏偏知识迁移
- 量化偏数值压缩

## 7. 本章速记

- 这章低优先级
- 压缩目标：更小、更快、更省
- 三大代表：剪枝、蒸馏、量化

# 14 Dimension Reduction：降维与 PCA

## 1. 老师点名重点

- **PCA 是必考重点。**
- 要掌握：
  - PCA 原理
  - 如何找主成分
  - 关键公式
- 降维思想和应用要理解。

## 2. 本章不考 / 低优先级

- 没有明确排除项。
- 但老师更重视**PCA 核心原理和流程**，不是复杂证明。

## 3. 结合 PPT 必须掌握的内容

PPT 这章反复强调：

- 投影后要尽量保留差异，**方差大更好**
- 主成分之间要**正交**
- 对角化可以让不同维度彼此独立
- 如果投影方向选错，会把原本可区分的类别压得分不开

这正是 PCA 的核心直觉。

## 4. 高频知识点整理

### 4.1 为什么要降维

目的：

- 压缩特征维度
- 去冗余
- 降噪
- 便于可视化
- 提高后续模型效率

### 4.2 PCA 的核心思想

PCA 要找一个新的坐标系，使得：

1. 第一主成分方向上数据方差最大
2. 第二主成分与第一主成分正交，且方差次大
3. 依次类推

也就是说：

> 选择最能保留数据差异的投影方向。

### 4.3 PCA 的标准步骤

1. 对数据做中心化  
   `x_i <- x_i - mean(x)`
2. 计算协方差矩阵  
   `Sigma = (1/n) * Σ (x_i - mu)(x_i - mu)^T`
3. 求协方差矩阵的特征值和特征向量
4. 按特征值从大到小排序
5. 取前 `k` 个特征向量组成投影矩阵 `W_k`
6. 做投影：
   `z = W_k^T (x - mu)`

### 4.4 为什么主成分要正交

PPT 里说得很直白：

- 如果方向彼此正交，就互不影响
- 内积为 0

这有助于：

- 避免重复表示同一类信息
- 让新的特征更独立

### 4.5 PCA 的局限

- PCA 是**无监督**方法
- 它只看方差，不看类别标签
- 所以“方差最大”不一定等于“分类最有利”

PPT 里“投影到红线导致类别分不开”的例子，就是在提醒这一点。

## 5. 易混点 / 易错点

- PCA 选的是**方差最大的方向**，不是“样本最多的方向”。
- PCA 是无监督降维，不利用标签。
- 特征值越大，对应方向保留的信息通常越多。
- 主成分是新的坐标方向，不是原来某一个单独特征。

## 6. 关键例题

### 例题 1：主成分判断题

**题目：**  
若二维数据中心化后的协方差矩阵为

`Sigma = [[9,0],[0,1]]`

问第一主成分方向是什么？为什么？

**答案要点：**

- 特征值分别为 9 和 1。
- 第一主成分对应最大特征值 9。
- 因此第一主成分方向就是 `x1` 轴方向。
- 原因：该方向方差最大，保留的信息最多。

### 例题 2：为什么 PCA 可能不利于分类？

**题目：**  
说明为什么 PCA 虽然保留了总体方差，却可能让两个类别更难区分。

**答案要点：**

- PCA 不利用标签。
- 它关心的是整体方差，不关心类别边界。
- 如果类间可分信息不在最大方差方向上，降维后可能把类别压得更近。

## 7. 本章速记

- PCA：最重要的降维方法
- 目标：保留最大方差
- 步骤：中心化 -> 协方差 -> 特征分解 -> 取前 k 个主成分
- 主成分要正交
- PCA 无监督，不一定最利于分类

# 15 Anomaly Detection：异常检测

## 1. 老师点名重点

- **异常检测原理是重点。**
- 基本方法与应用场景要理解。

## 2. 本章不考 / 低优先级

- 没有明确排除项。
- 重点在原理，不在复杂推导。

## 3. 结合 PPT 必须掌握的内容

PPT 一开始就强调了一个容易考的点：

> 异常只是“不一样”，**不特指不好**。

PPT 里的场景包括：

- 正常请求 vs 攻击行为
- 正常刷卡行为 vs 异常刷卡
- 客观发言 vs 极端发言
- 位于等高线之外

所以老师显然希望你理解：

- 异常是**相对正常模式而言的偏离**
- 它可能是坏的，也可能只是罕见

## 4. 高频知识点整理

### 4.1 什么是异常

异常样本是指：

- 与大多数正常样本相比明显不同
- 处在低密度区域
- 或不符合已学到的正常模式

### 4.2 异常检测的任务目标

核心是：

- 先学到“正常长什么样”
- 再判断新样本是否明显不像正常样本

### 4.3 常见思路

#### 密度 / 概率方法

- 正常样本集中在高密度区域
- 低概率点更可能异常

#### 距离方法

- 离大多数样本很远的点更可能异常

#### 重构误差方法

- 用自编码器等模型学习正常样本结构
- 重构误差大说明样本不像正常数据

#### 边界方法

- 学正常样本的包围边界
- 落到边界外更可能异常

### 4.4 “等高线之外”的直观理解

PPT 的“位于等高线之外”可以这样理解：

- 模型已经学出了正常样本的大致分布轮廓
- 落在高密度轮廓之外的样本，更可能是异常

## 5. 易混点 / 易错点

- 异常 ≠ 一定有害；它只是“偏离正常模式”。
- 少见 ≠ 一定异常，要结合分布和任务定义。
- 异常检测常常只有正常数据或正常数据更多，因此与普通分类问题不同。

## 6. 关键例题

### 例题 1：为什么“异常”不一定是坏事？

**题目：**  
请解释“异常只是和大多数样本不一样，不一定代表坏”的含义。

**答案要点：**

- 异常是统计意义或分布意义上的偏离。
- 它可能是攻击、欺诈，也可能只是稀有但正常的情况。
- 所以异常检测先回答“像不像正常样本”，再由业务语义判断好坏。

### 例题 2：等高线判断题

**题目：**  
某样本点明显落在正常数据分布的高密度等高线之外，说明什么？

**答案要点：**

- 它处在低密度区域
- 与正常模式差异大
- 更可能被判为异常样本

## 7. 本章速记

- 异常：明显不像正常样本
- 不一样，不一定不好
- 核心：先学正常，再找偏离
- 密度低、边界外、重构差，都可能说明异常

# 16 GAN：生成对抗网络

## 1. 老师点名重点

- **GAN 是重点章节。**
- 必须掌握：
  - Generator 做什么
  - Discriminator 做什么
  - GAN 如何一步一步训练
  - 伪代码 / 算法流程在干什么

## 2. 本章不考 / 低优先级

- 没有明确排除项。
- 但考试更可能考**原理、角色分工、流程**，而不是复杂证明。

## 3. 结合 PPT 必须掌握的内容

PPT 对 GAN 的描述非常有辨识度：

- 生成任务比分类任务更难
- Generator 和 Discriminator **“是朋友也是敌人”**
- Discriminator 更像站在全局视角做批评
- 生成图片时，难点在于“各部分之间的连接关系是对的”

也就是说，GAN 的难点不只是“看起来像”，还包括：

- 局部细节
- 整体结构
- 训练时双方博弈的稳定性

## 4. 高频知识点整理

### 4.1 GAN 由谁组成

#### Generator（生成器）G

- 输入：随机噪声 `z`
- 输出：生成样本 `G(z)`
- 目标：骗过判别器，让假样本看起来像真的

#### Discriminator（判别器）D

- 输入：样本 `x`
- 输出：这个样本是真的概率
- 目标：区分真实样本和生成样本

### 4.2 为什么说“亦敌亦友”

- **敌对**：G 想骗过 D，D 想识破 G
- **合作**：D 的反馈又在帮助 G 变得更好

所以训练过程本质是**对抗博弈**。

### 4.3 GAN 的目标函数

经典形式：

`min_G max_D V(D,G) = E_x[log D(x)] + E_z[log(1 - D(G(z)))]`

可以这样理解：

- D 希望真实样本判成 1、假样本判成 0
- G 希望让 `D(G(z))` 尽量大

### 4.4 一次训练迭代的流程

1. 从真实数据集中采样真样本 `x`
2. 从噪声分布采样 `z`
3. 用 G 生成假样本 `G(z)`
4. 用真样本和假样本训练 D
5. 固定 D，用 D 的反馈更新 G
6. 重复迭代，直到 G 生成得越来越像真数据

### 4.5 GAN 为什么难训练

主要原因：

- G 和 D 实力不平衡会导致训练崩掉
- 容易模式崩塌（mode collapse）
- 只学到“看起来像”，不一定学到完整结构

PPT 里的“连接关系对不对”就是在提醒：  
图像生成不是只要局部纹理像，还要整体结构合理。

## 5. 易混点 / 易错点

- G 不是“凭空背答案”，而是从噪声分布里生成样本。
- D 不是最后要部署的唯一主体，但它训练期间非常关键。
- GAN 训练不是一步到位，而是 G、D 交替更新。
- 生成得“模糊像”不等于真正学到了完整数据分布。

## 6. 关键例题

### 例题 1：说明一次 GAN 训练迭代

**题目：**  
请用步骤说明 GAN 在一次训练迭代中 Generator 和 Discriminator 分别做了什么。

**答案要点：**

1. 从真实数据里抽样真样本。
2. 从随机噪声抽样，交给 G 生成假样本。
3. D 同时看真样本和假样本，学习区分真假。
4. 再固定 D，利用 D 给 G 的反馈来更新 G。
5. 目的：让 G 生成的样本越来越像真样本。

### 例题 2：为什么说生成任务比分类任务更难？

**题目：**  
结合 GAN 说明为什么图像生成通常比图像分类更难。

**答案要点：**

- 分类只要给出类别判断，属于“选答案”。
- 生成要自己构造完整输出，属于“写答案”。
- 既要局部像，也要整体结构对。
- 输出空间远大于分类空间，所以更难。

## 7. 本章速记

- GAN = G + D
- G：造假
- D：验假
- 二者对抗训练
- 训练流程：真样本 / 假样本训练 D，再用 D 反馈训练 G
- 难点：不稳定、模式崩塌、结构一致性

# 17 Meta Learning：元学习

## 1. 老师点名重点

- 元学习基本原理要知道。

## 2. 本章不考 / 低优先级

- 没有明确复杂推导要求。
- 重点是：知道它在解决什么问题、为什么叫“学习如何学习”。

## 3. 结合 PPT 必须掌握的内容

PPT 中很关键的两句话：

- **Meta learning 的输出是一个 function**
- 它是在学“根据资料找函数的能力”

还提到：

- 让机器自己决定原本由人手工设定的部分
- 常见场景是少样本字符识别

这说明元学习不是单纯再学一个分类器，而是在学：

> 遇到新任务时，怎样更快学会它。

## 4. 高频知识点整理

### 4.1 什么是元学习

元学习可以概括为：

> 学习“如何学习”。

普通机器学习：

- 学一个任务对应的函数 `f`

元学习：

- 学一个更高层的机制 `F`
- 让它能根据少量新数据，快速得到适合该任务的 `f`

### 4.2 元学习解决什么问题

核心问题：

- 新任务样本很少
- 但希望模型适应很快

典型应用：

- few-shot classification
- 快速适应新用户 / 新领域

### 4.3 为什么它叫“function of function”

因为：

- 基础模型输出的是任务函数 `f`
- 元学习想学的是“如何得到这个 `f`”的规则 `F`

所以可以理解成：

- 普通学习：学解题者
- 元学习：学“如何训练出更快上手的解题者”

### 4.4 与迁移学习的区别

- 迁移学习：把已有知识迁移到新任务
- 元学习：更强调快速适应机制本身

二者有关，但关注点不同。

## 5. 易混点 / 易错点

- 元学习不是“再学一次普通模型”，而是学适应新任务的能力。
- 它常常服务于少样本场景，但不限于少样本。
- 元学习和迁移学习相关，但不能直接画等号。

## 6. 关键例题

### 例题：为什么叫“学习如何学习”？

**题目：**  
请结合 few-shot classification 场景，解释元学习为什么叫“学习如何学习”。

**答案要点：**

- 在 few-shot 里，每个新类别只有很少样本。
- 如果像普通监督学习那样从头训练，会很慢且数据不够。
- 元学习通过大量任务训练，学会“看到少量样本后应如何快速调整模型”。
- 所以它学到的不是单一任务答案，而是快速适应机制。

## 7. 本章速记

- 元学习：learning to learn
- 普通学习学 `f`
- 元学习学得到 `f` 的机制 `F`
- 场景：few-shot、快速适应

# 18 Lifelong Learning：终身学习 / 持续学习

## 1. 老师点名重点

- 基本原理理解即可。
- 但“灾难性遗忘”这个词基本必须知道。

## 2. 本章不考 / 低优先级

- 没有强调复杂推导。
- 重点在概念与基本方法。

## 3. 结合 PPT 必须掌握的内容

PPT 这章最关键的信息有三条：

- **Catastrophic Forgetting**
- 用参数重要性来约束“哪些能动、哪些尽量别动”
- 学新任务时，如果旧数据不能保留，可以生成旧任务的 **pseudo-data**

这几乎就是整章的核心。

## 4. 高频知识点整理

### 4.1 什么是终身学习

终身学习研究的是：

- 模型按顺序不断接收新任务
- 希望学会新任务时，不要把旧任务忘得太厉害

### 4.2 灾难性遗忘

这是最常考概念。

含义：

- 模型学新任务后
- 旧任务性能大幅下降

原因：

- 同一组参数被新任务强烈改写
- 原本服务旧任务的重要参数被破坏

### 4.3 参数重要性约束思想

PPT 给出的思想非常直观：

- 对旧任务重要的参数，尽量不要动
- 对旧任务不重要的参数，可以自由更新

典型形式可以写成：

`L_total = L_new + lambda * Σ b_i * (theta_i - theta_i_old)^2`

其中：

- `b_i` 大：说明该参数对旧任务重要
- `b_i` 小：说明它不那么重要

PPT 还强调了两个极端：

- `b_i = 0`：这项约束消失，可以随便动
- `b_i = infinity`：这个参数几乎被锁死，不能改

### 4.4 伪数据回放 / 生成回放

如果旧任务原始数据不能保存，怎么办？

PPT 的做法是：

- 让生成模型生成旧任务伪数据
- 在学新任务时，一起拿来训练

作用：

- 给模型“提醒”旧任务长什么样
- 减少遗忘

## 5. 易混点 / 易错点

- 终身学习不是普通 fine-tuning。
- 核心目标不是只学新任务，而是**边学新任务边保留旧知识**。
- 约束越强不一定越好，太强可能让新任务学不进去。

## 6. 关键例题

### 例题 1：解释 `b_i` 的含义

**题目：**  
在终身学习的参数约束项里，`b_i` 很大和很小分别意味着什么？

**答案要点：**

- `b_i` 很大：该参数对旧任务很重要，更新时应尽量保持不变。
- `b_i` 很小：该参数对旧任务不太重要，可以较自由地更新。

### 例题 2：为什么要用 pseudo-data？

**题目：**  
如果任务 1 的真实数据不能再使用，为什么生成旧任务的 pseudo-data 能帮助终身学习？

**答案要点：**

- 因为模型在学习任务 2 时容易忘记任务 1。
- 伪数据虽然不是真实旧数据，但能近似提醒模型旧任务分布。
- 相当于给旧任务提供“回放记忆”，减轻遗忘。

## 7. 本章速记

- 终身学习：持续学新任务，还要记住旧任务
- 核心难点：Catastrophic Forgetting
- 解决思路：
  - 重要参数少动
  - 旧任务回放 / 伪数据回放

# 19 Stable Diffusion：扩散模型基础

## 1. 老师点名重点

- diffusion 基本原理要知道。
- 扩散过程 / 去噪过程要理解。
- Stable Diffusion 的核心部件要能说清。

## 2. 本章不考 / 低优先级

- 未强调复杂数学推导。
- 重点是整体流程和关键组件。

## 3. 结合 PPT 必须掌握的内容

PPT 明确出现了这些关键词：

- 噪声
- 中间产物
- 图片的压缩版本
- Noise Predictor
- Stable Diffusion 是 **latent diffusion model**
- 核心生成网络常是 **U-Net**

所以考试最应该掌握的是：

> Stable Diffusion 不是直接在原始像素空间里硬生生去噪，而是在潜空间里做扩散与去噪。

## 4. 高频知识点整理

### 4.1 扩散模型的基本思想

扩散模型分两部分：

#### 正向扩散

- 逐步给真实数据加噪声
- 最后变成近似纯噪声

#### 反向去噪

- 学习如何把噪声一步步还原成数据

训练好后，生成时就从随机噪声开始，反复去噪，得到样本。

### 4.2 Stable Diffusion 为什么“Stable”

这类模型常在**潜空间（latent space）**中工作：

- 先把图片压缩成更小的潜表示
- 在潜空间里做扩散 / 去噪
- 最后再解码回图片

好处：

- 计算量更低
- 生成速度更快
- 资源消耗更可控

### 4.3 Noise Predictor / U-Net 的作用

PPT 明确说：

- 核心网络通常就是 **noise predictor**
- 它也叫 denoising network / denoise module
- 但它**不是整个 Stable Diffusion 系统的全部**

它的任务是：

- 输入当前带噪潜变量
- 预测噪声或去噪方向
- 指导反向扩散过程

### 4.4 Stable Diffusion 的大致流程

1. 把图像编码成潜表示
2. 在潜空间逐步加噪训练
3. 训练 U-Net 学会预测噪声
4. 生成时从随机噪声开始
5. 反复去噪
6. 解码回图像

### 4.5 FID（了解）

PPT 中还出现了 Fréchet Distance 相关内容。  
复习时知道它是**评价生成图像分布与真实图像分布接近程度**的指标即可，不必深究推导。

## 5. 易混点 / 易错点

- Stable Diffusion 不是“直接在原图像空间一步出图”，而是常在潜空间中完成主要生成过程。
- U-Net / noise predictor 是核心组件，但不是整个系统全部。
- 正向扩散是加噪，生成时真正用的是反向去噪。

## 6. 关键例题

### 例题 1：说明 Stable Diffusion 生成流程

**题目：**  
请用步骤说明 Stable Diffusion 生成一张图的大致过程。

**答案要点：**

1. 从随机噪声开始。
2. 在潜空间中输入给 U-Net / noise predictor。
3. 网络预测当前噪声，应如何去掉一部分噪声。
4. 经过多步迭代，潜变量越来越像真实图像表示。
5. 最后用解码器把潜变量还原成图像。

### 例题 2：为什么要在潜空间做扩散？

**题目：**  
为什么 Stable Diffusion 更常在潜空间而不是原始像素空间做扩散？

**答案要点：**

- 潜表示维度更低，计算更省。
- 训练和采样速度更快。
- 可以在保留主要语义结构的同时减少直接处理超大图像的成本。

## 7. 本章速记

- 扩散模型：加噪训练，去噪生成
- Stable Diffusion：latent diffusion
- 核心网络：U-Net / noise predictor
- 生成流程：噪声 -> 多步去噪 -> 图像
