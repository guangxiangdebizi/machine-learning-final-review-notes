## 02 Regression

### 重点

- 回归输出：**连续值**
- 基本形式：`y_hat = w^T x + b`
- 常见损失：`MSE = (1/n) * sum_i (y_hat_i - y_i)^2`
- 正则化：`Loss = MSE + lambda * ||w||^2`
- 回归 vs 分类

### 例题 1

**题目：**  
“根据房屋面积预测房价”和“判断邮件是否垃圾邮件”哪个是回归？

**答案：**

- 房价预测是回归，因为输出是连续值
- 垃圾邮件识别是分类，因为输出是离散类别

### 例题 2

**题目：**  
为什么加正则化可能让训练误差上升，却让测试误差下降？

**答案：**

- 因为正则化限制模型复杂度
- 训练拟合能力变弱，所以训练误差可能上升
- 但过拟合减轻，测试误差可能下降

### 考场一句话

- 回归只看一件事：输出是不是连续值。

## 03 Gradient Descent（重点）

### 老师重点

- 梯度下降流程、如何下降、学习率、SGD、优化器、练习题
- 高阶数学推导不重点

### 重点

- 梯度：loss 增大最快方向
- 更新：`w_(t+1) = w_t - eta * (dL/dw_t)`
- 学习率大：震荡；学习率小：收敛慢
- SGD / mini-batch
- Adam / RMSProp / Adagrad / SGDM
- Feature Scaling 很重要
- **loss 不保证每一步都下降**

### 例题 1：标准迭代题

**题目：**  
`L(w)=w^2+5w+6`，`eta=0.1`，`w0=2`，求 3 次迭代后的 `w3`。

### 计算

1. 求导：`dL/dw = 2w + 5`
2. 更新：`w_new = w_old - 0.1*(2w_old+5)`
3. 迭代：
   - `w1 = 2 - 0.1*(9) = 1.1`
   - `w2 = 1.1 - 0.1*(7.2) = 0.38`
   - `w3 = 0.38 - 0.1*(5.76) = -0.196`

**答案：** `w3 = -0.196`

### 例题 2：概念判断题

**题目：**  
为什么学习率太大会导致训练不稳定？

**答案：**

- 因为每次更新步子太大
- 容易越过最优点
- 容易在最优点附近来回震荡

### 例题 3：Feature Scaling

**题目：**  
为什么特征尺度差太大会让梯度下降变慢？

**答案：**

- 不同维度变化速度差异大
- 等高线狭长，更新路径震荡
- 收敛慢、学习率难调

### 考场一句话

- 梯度不是下降方向，**负梯度**才是下降方向。

## 05 Logistic Regression（重点）

### 老师重点

- Logistic Regression 原理
- 激活函数作用
- 三步骤在本章中的体现
- sigmoid 基本形式要会

### 重点

- 逻辑回归本质是**分类模型**
- `z = w^T x + b`
- `p(y=1|x)=sigmoid(z)=1/(1+e^(-z))`
- 交叉熵：`L = -[y log p + (1-y) log(1-p)]`
- 多分类看 softmax
- 逻辑回归只能做**线性分割**
- 机器学习三步骤在本章中的体现

### 例题 1：概率 + 损失计算

**题目：**  
已知 `x=[1,2]`，`w=[0.5,-1]`，`b=0`，真实标签 `y=1`。求 `p` 和交叉熵损失。

### 计算

1. `z = 0.5*1 + (-1)*2 = -1.5`
2. `p = sigmoid(-1.5) ≈ 0.1824`
3. `L = -log(0.1824) ≈ 1.701`

**答案：** `p ≈ 0.1824`，`L ≈ 1.701`

### 例题 2：模型限制

**题目：**  
为什么逻辑回归难以直接解决 XOR 一类问题？

**答案：**

- 因为逻辑回归只能形成线性决策边界
- XOR 不是线性可分

### 例题 3：三步骤对应

**题目：**  
逻辑回归里的“模型、loss、优化”分别是什么？

**答案：**

- 模型：`p(y=1|x)=sigmoid(w^T x+b)`
- loss：交叉熵
- 优化：梯度下降 / Adam 等

### 考场一句话

- likelihood 越大越好；训练时常转成最小化交叉熵。

## 06 Deep Learning（重点）

### 老师重点

- 前向传播必须会算
- ReLU / Sigmoid 公式要记
- 反向传播过程理解
- 可出计算题，可带计算器

### 重点

- 输入层 / 隐藏层 / 输出层
- 前向传播：**乘权重 -> 加 bias -> 过激活**
- `z^(l)=W^(l)a^(l-1)+b^(l)`，`a^(l)=f(z^(l))`
- `ReLU(z)=max(0,z)`，`sigmoid(z)=1/(1+e^(-z))`
- 本章也按：**模型 -> loss -> 优化**
- 前向传播手算必须会

### 例题 1：前向传播手算

**题目：**  
输入 `x=[1,2]^T`；隐藏层  
`W1=[[1,0],[-1,1]]`，`b1=[0,1]^T`，激活函数 ReLU；  
输出层 `W2=[0.5,-1]`，`b2=0`，输出层激活函数 sigmoid。求最终输出。

### 计算

1. 隐藏层线性输出：
   - `z1_1 = 1*1 + 0*2 + 0 = 1`
   - `z1_2 = -1*1 + 1*2 + 1 = 2`
2. 过 ReLU：`a1=[1,2]^T`
3. 输出层：`z2 = 0.5*1 + (-1)*2 = -1.5`
4. `y_hat = sigmoid(-1.5) ≈ 0.1824`

**答案：** `y_hat ≈ 0.1824`

### 例题 2：为什么要激活函数

**题目：**  
为什么神经网络不能每层都只做线性变换？

**答案：**

- 多层线性变换叠加后仍是线性变换
- 没有非线性就无法表达复杂关系

### 例题 3：激活函数记忆题

**题目：**  
写出 ReLU 与 sigmoid 公式。

**答案：**

- `ReLU(z)=max(0,z)`
- `sigmoid(z)=1/(1+e^(-z))`

### 考场一句话

- 前向传播顺序别写反：**先线性，后激活**。

## 07 Backpropagation（重点）

### 老师重点

- 反向传播完整流程
- 前向 + 反向联合理解
- 不考原题，考换形式

### 重点

- 本质：链式法则求梯度
- 流程：前向传播 -> 算 loss -> 反向传播 -> 更新参数
- sigmoid + 二分类交叉熵下：`delta_out = y_hat - y`
- 前向 + 反向要能连成完整链路

### 例题 1：梯度计算

**题目：**  
已知 `x=1`，`y=1`，`w1=0.5`，`b1=0`，`w2=1.0`，`b2=0`，隐藏层和输出层都用 sigmoid，损失函数用二分类交叉熵。求 `dL/dw2`、`dL/dw1`。

### 计算

1. 前向：
   - `z1 = 0.5`
   - `h = sigmoid(0.5) ≈ 0.6225`
   - `z2 = 0.6225`
   - `y_hat = sigmoid(0.6225) ≈ 0.6508`
2. 输出层误差：
   - `delta_out = y_hat - y ≈ -0.3492`
3. 输出层梯度：
   - `dL/dw2 = delta_out * h ≈ -0.2174`
4. 隐藏层误差：
   - `delta_hidden = delta_out * w2 * h * (1-h) ≈ -0.0821`
5. 隐藏层梯度：
   - `dL/dw1 = delta_hidden * x ≈ -0.0821`

**答案：**

- `dL/dw2 ≈ -0.2174`
- `dL/dw1 ≈ -0.0821`

### 例题 2：流程题

**题目：**  
反向传播的基本步骤是什么？

**答案：**

1. 先前向算输出
2. 算损失
3. 从输出层开始求误差项
4. 按链式法则往前传播
5. 得到梯度后更新参数

### 例题 3：为什么深层前面层更难训练

**题目：**  
为什么深层网络越靠近输入层的参数往往越难训练？

**答案：**

- 因为梯度往前传时会不断乘导数
- 导数若普遍小于 1，梯度会逐层变小

### 考场一句话

- 不考原题，但大概率考同结构换皮题。

## 12 Attack and Defense（重点）

### 老师重点

- FGSM
- 攻击与防御基本思想
- 经典简单算法理解

### 重点

- 对抗攻击：小扰动，大误判
- `L_infinity`：限制单维最大改动
- FGSM：`x_adv = x + epsilon * sign(grad_x L)`
- 防御：平滑化、对抗训练

### 例题 1：FGSM 手算

**题目：**  
设 `x=[0.4,0.6,0.2]`，`epsilon=0.1`，`grad_x L=[0.2,-1.5,0]`，用 FGSM 生成对抗样本。

### 计算

1. `sign(grad_x L) = [1,-1,0]`
2. `x_adv = x + 0.1*[1,-1,0]`
3. `x_adv = [0.5,0.5,0.2]`

**答案：** `x_adv = [0.5,0.5,0.2]`

### 例题 2：概念题

**题目：**  
为什么 `epsilon` 不能取得过大？

**答案：**

- 太大会让扰动容易被人察觉
- 失去“看起来几乎不变”的攻击意义

### 例题 3：防御题

**题目：**  
为什么对抗训练能提高鲁棒性？

**答案：**

- 因为训练时就让模型见过对抗样本
- 模型会学到对这些扰动不那么敏感

### 考场一句话

- FGSM 改的是输入，不是模型参数。

## 14 Dimension Reduction / PCA（重点）

### 老师重点

- PCA 是重点
- PCA 原理、主成分怎么找、公式要理解

### 重点

- PCA = 最大方差投影
- 协方差矩阵：`Sigma = (1/n) * sum_i (x_i - mu)(x_i - mu)^T`
- 第一主成分：`max_w w^T Sigma w, s.t. ||w||=1`
- 流程：中心化 -> 协方差 -> 特征分解 -> 取前 k 个主成分 -> 投影
- 主成分正交；PCA 无监督

### 例题 1：主成分方向判断

**题目：**  
若二维数据中心化后的协方差矩阵为  
`Sigma = [[9,0],[0,1]]`，求第一主成分方向。

### 计算

1. 特征值分别为 `9` 和 `1`
2. 第一主成分对应最大特征值 `9`
3. 所以第一主成分方向是 `x1` 轴方向

**答案：** 第一主成分是 `x1` 方向

### 例题 2：流程题

**题目：**  
PCA 的标准步骤是什么？

**答案：**

1. 中心化
2. 求协方差矩阵
3. 特征值 / 特征向量分解
4. 取前 k 个主成分
5. 投影到新空间

### 例题 3：概念题

**题目：**  
为什么 PCA 可能不利于分类？

**答案：**

- 因为 PCA 不利用标签
- 它保留的是总体方差，不一定保留最有利于分类的方向

### 例题 4：投影题

**题目：**  
若第一主成分方向为 `w=[1,0]^T`，样本中心化后为 `x=[3,1]^T`，投影坐标是多少？

### 计算

1. 投影公式：`z = w^T x`
2. `z = [1,0] * [3,1]^T = 3`

**答案：** `z = 3`

### 考场一句话

- PCA 保证去相关 / 正交，**不保证独立**。

## 15 Anomaly Detection（重点）

### 老师重点

- 异常检测原理是重点
- 基本方法理解

### 重点

- 异常 = 明显不像正常样本
- 先学正常，再判偏离
- 密度 / 距离 / 重构误差 / 边界
- 异常不一定代表“坏”，只是“不一样”

### 例题 1

**题目：**  
一个样本明显落在正常数据高密度等高线之外，说明什么？

**答案：**

- 位于低密度区域
- 与正常模式差异大
- 更可能是异常

### 例题 2

**题目：**  
为什么说异常不一定代表坏？

**答案：**

- 因为异常只是统计意义上的偏离
- 可能是攻击，也可能只是稀有但正常的情况

### 例题 3

**题目：**  
密度法、距离法、重构误差法分别在看什么？

**答案：**

- 密度法：看样本是否处在低概率 / 低密度区域
- 距离法：看是否离正常样本整体太远
- 重构误差法：看模型能否把样本重构得像正常样本

### 考场一句话

- 异常检测先回答“像不像正常样本”，再谈好坏。

## 16 GAN（重点）

### 老师重点

- GAN 是重点章节
- Generator / Discriminator
- 工作流程、算法步骤、伪代码理解

### 重点

- G：生成器；D：判别器
- 对抗训练
- 流程：真样本 -> 噪声 -> G 生成假样本 -> 训 D -> 固定 D 训 G
- 难点：不稳定、mode collapse、整体结构难学

### 例题 1：流程题

**题目：**  
请说明一次 GAN 训练迭代中 G 和 D 各自做什么。

**答案：**

1. 抽真实样本
2. 抽噪声，G 生成假样本
3. D 用真假样本学习区分真假
4. 固定 D，用 D 的反馈更新 G

### 例题 2：概念题

**题目：**  
为什么说生成任务比分类任务更难？

**答案：**

- 分类是“选答案”
- 生成是“自己写答案”
- 既要局部像，也要整体结构对

### 例题 3：难点题

**题目：**  
什么是 mode collapse？

**答案：**

- 生成器只会生成少数几种模式
- 无法覆盖真实数据分布的多样性

### 考场一句话

- G 造假，D 验假，二者交替训练。

## 19 Stable Diffusion（重点）

### 老师重点

- diffusion 基本原理
- 扩散过程理解

### 重点

- 扩散模型：加噪训练，去噪生成
- Stable Diffusion 重点：latent diffusion
- 核心部件：U-Net / noise predictor
- 流程：编码到潜空间 -> 从噪声开始 -> 多步去噪 -> 解码成图像

### 例题 1

**题目：**  
为什么 Stable Diffusion 常在潜空间而不是原始像素空间做扩散？

**答案：**

- 潜空间维度更低
- 计算量更小
- 训练和采样更快

### 例题 2

**题目：**  
Stable Diffusion 生成一张图的大致流程是什么？

**答案：**

1. 图像编码到潜空间
2. 从随机噪声开始
3. U-Net 逐步预测噪声并去噪
4. 最后解码为图像

### 考场一句话

- 重点不是“稳定”，而是 **latent diffusion**。
